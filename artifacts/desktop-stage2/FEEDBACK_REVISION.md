# 데스크톱 확대판 피드백 반영 보고

## 반영 기준

- 과거 데스크톱 UI를 복원하지 않고 최신 모바일 카드와 기능 순서를 그대로 사용한다.
- 데스크톱에서는 공통 기능을 다시 만들지 않고 같은 컴포넌트의 폭과 배치만 조정한다.
- 별도의 우측 패널은 사용자가 지정한 보조 영역에만 사용한다.

## 수정 내용

- 메트로놈: 모바일 카드 순서를 유지한 확대형 배치로 변경하고 백킹루프 버튼 4열의 겹침을 제거했다.
- 단일 음·스케일: 참고 지판은 왼쪽, 같은 BPM·메트로놈 덱은 오른쪽에 배치했다.
- 스케일 백킹루프: 좁은 우측 열에서도 플레이어와 4개 조작 버튼이 부모 폭을 넘지 않도록 보정했다.
- 리듬·코드: 1106px로 늘어나던 접힌 BPM 패널을 진행 불러오기 오른쪽의 280~334px 보조 열로 정돈했다.
- 미니코드반주: 편집기·타임라인은 왼쪽, BPM과 반주 사운드는 오른쪽에 배치했다.
- 지판보기: 현재 지판과 코드 빌더는 왼쪽, 전체 코드표는 오른쪽 내부 스크롤 패널로 배치했다.
- 슈팅게임: 하단의 시작·마이크·일시정지·리셋·음표 중복 패널을 렌더 트리에서 제거했다. 상단 HUD, 지판 안내의 마이크, 게임 영역 클릭 일시정지, 일시정지 오버레이의 계속·리셋은 유지된다.

## 실제 브라우저 검증

- 1280×720, 1366×768, 1920×1080, 2560×1440에서 변경 화면을 확인했다.
- 메트로놈은 1280×720에서 백킹루프 하단과 고정 내비게이션 사이에 양수 간격을 확보했다.
- 미니코드반주와 지판보기는 데스크톱 문서 폭을 넘는 가로 스크롤이 없다.
- 지판보기 전체 코드표는 오른쪽 패널 안에서 세로 스크롤된다.
- 슈팅게임 플레이 영역 비율은 0.515882로 기존 390:756 비율을 유지하며 하단 중복 패널은 0개다.
- 390×844 메트로놈의 패널, 고급 도크, 박자판, BPM 카드 위치와 크기는 이전 기준값과 동일하다.
- 390px 모바일에서 단일·스케일·리듬·미니코드·지판보기는 단일 열을 유지하고 `DesktopLayout`은 렌더되지 않는다.
- 680px 모바일 가로모드에서도 `DesktopLayout`은 렌더되지 않는다.

## 자동 검증

- 관련 회귀 테스트: 55/55 통과
- 프로덕션 빌드: 성공
- 전체 테스트: 기존과 동일한 2건만 실패
  - `metronome-wheel-picker.test.mjs`: 기존 `scroll-snap` 정규식 실패
  - `shooter-map-performance-policy.test.mjs`: 기존 `reduced !== full` 실패
