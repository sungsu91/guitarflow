# FRETIVA LAB 데스크톱 보완 1·2단계 보고

## 이번 작업 범위

- 1단계: 반응형 분기, 주요 화면, 공용 메뉴·모달, 모바일 기준 화면 진단
- 2단계: 기존 `DesktopLayout` 경계 안에서 데스크톱 메트로놈 1개 화면 개선
- 제외: 나머지 화면의 본격적인 데스크톱 재배치, 오디오·마이크·판정·저장 로직 변경

## 분기 구조

- 모바일 레이아웃: `680px` 이하 또는 모바일 UA/iPad 계열 터치 장치
- 데스크톱 레이아웃: 최소 가시 폭, `hover: hover`, `pointer: fine`, 비모바일 UA 조건을 모두 만족할 때만 `DesktopLayout` 렌더
- 화면 프로필: compact/tablet/wide, portrait/landscape, short/tall 클래스를 별도로 부여
- 이번 CSS는 모두 `.desktopLayout` 아래에 있어 모바일·태블릿·폴더블·모바일 가로모드에는 적용되지 않음

## 변경 파일

- `src/layouts/desktop-layout.css`: 데스크톱 메트로놈 전용 작업공간, 낮은 창 스크롤 억제, 백킹 열 최소 폭 보정, 고급 팝업 최대 높이 보정
- `tests/desktop-metronome-layout.test.mjs`: 단일 공유 트리와 데스크톱 런타임 게이트 회귀 검사

기존 변경 상태였던 `App.jsx`, `responsive-play-focus.css`, `viewportProfile.js` 등은 수정하지 않았습니다.

## 검증 결과

- 실제 브라우저: 1280×720, 1366×768, 1920×1080, 2560×1440, 1280×600
- 모든 데스크톱 검증 크기: 문서 폭·높이와 뷰포트 일치, 화면 이탈 요소 0건
- 팝업: Automator, 박자 드롭다운, 백킹 재생목록, 도움말 화면 이탈 0건
- 테마: 라이트·골드 다크 모두 렌더 확인
- 모바일: 390×844와 680×390에서 변경 전후 핵심 패널의 위치·폭·높이 동일
- 분기 경계: 1023·1024px 기존 비데스크톱 유지, 현재 런타임 조건을 모두 만족한 1040px에서 데스크톱 전환 확인
- 상태 보존: BPM 90 상태가 데스크톱→모바일→데스크톱 및 지판보기 왕복 후에도 유지
- 슈팅게임: 변경 전후 플레이 비율 0.515882 동일
- 빌드: 성공
- 관련 회귀 테스트: 32/32 통과
- 전체 테스트: 397개 중 395개 통과, 아래 기존 2개 실패가 변경 전후 동일
  - `metronome-wheel-picker.test.mjs`: 기존 `scroll-snap` 정규식 실패
  - `shooter-map-performance-policy.test.mjs`: 기존 `reduced !== full` 실패
