# 리듬 진행바

## 적용
- 에튀드와 구조화된 내 악보가 공유하는 연습 화면. PDF/이미지에는 좌표나 시간을 추정하지 않는다.
- 기존 메뉴: 화면 따라가기(줄/마디전환/끔), 독립 리듬 진행바 체크박스. 서로 해제하지 않는다.
- ScorePlayback의 AudioContext 시간, 기존 반복 경로 및 playbackSlots를 재사용한다. 진행바 전용 누적 시계는 없다.
- 렌더링 후 note/rest 좌표와 onset을 연결해 구간별 선형 보간한다. 마디 끝은 해당 마디 capacity의 마지막 앵커다. 박자표/조표 앞 여백은 포함하지 않는다.
- 한 프레임에 진행선 좌표만 변경한다. 기호 색은 시간 구간이 바뀔 때 변경한다. 악보 렌더링은 보기/크기/확대 등의 변경 때만 한다.
- 반복 복귀는 즉시 이동한다. 재생 중 BPM/클릭 세분 변경은 기존 transport가 현재 tick에서 일정을 다시 구성하며, 두 소리의 음소거는 시간축을 멈추지 않는다.

## 주법
- 같은 높이·현의 실제 연속된 tieTo는 붙임줄 유지, 다시 피킹하는 강조 제외. 마디 경계 및 반복 경로를 확인한다.
- H/P/S는 출발·도착 음의 onset에 맞춰 기존 곡선/선/글자에 색을 준다. 슬라이드 내부 시작 시각이나 음높이 경로는 새로 계산하지 않는다.
- 부분 슬라이드 화음은 연결된 현과 다른 현의 새 피킹을 구분한다.
- 팜뮤트, 비브라토, 아르페지오 방향, 하모닉스/뮤트음 및 피킹/운지 표시는 기존 기호만 강조한다. 시간이나 음표를 추가하지 않는다.
- 건반 큰보표 붙임줄도 같은 연결 메타데이터를 사용한다.

## 데이터/기존 렌더러 한계
- 현재 편집 문서는 독립 성부별 리듬을 저장하지 않는다. 양손/화음은 공통 이벤트를 공유한다. 진행 계산은 명시 onset을 기준으로 정렬·중복 통합하며 성부 길이를 합산하지 않는다.
- 가져온 구형 bend/ghost/grace 데이터는 보존만 한다. 편집기에서 작성한 note.bendEffect는 올림·유지·내림·왕복 표시와 참고 재생을 지원하며, letRing은 열린 곡선과 여운 유지로 지원한다.
- 마디 경계를 잇는 H/P/SL 기호는 기존 렌더러의 미지원 항목이다. 연결 시간 상태는 유지하지만 없는 기호를 강조할 수 없다. 마디를 넘는 붙임줄 표시는 지원한다.
- 슬라이드의 세부 시작 시각, 비브라토 속도/폭, 아르페지오 각 현별 실제 연주 시각은 저장 데이터에 없다. 진행바는 작성 음길이와 onset만 사용한다.

- scripts/verify-rhythm-progress.mjs + rhythm-progress-fixture.jsx: 390/1440 화면의 실제 React/SVG와 Web Audio. 23개 시각의 좌표 일치, 세 보기·확대·회전, 화면 따라가기와 진행바 독립 동작, 양쪽 음소거, 선택적 악보 소리 토글, 클릭 세분, BPM 변경, 일시정지·재개, seek/반복 복귀, 애니메이션 중 SVG 재생성 없음.
- 전체 테스트 및 프로덕션 빌드 실행. 모바일 실제 에튀드 설정 메뉴도 시각 확인.
