# 추가 주법

주법 메뉴에서 열린 붙임줄, 슬라이드 아웃 상행/하행, 괄호 음표, 벤드 올림/유지/릴리스/올렸다 내림을 선택한다. 기존 H/P·슬라이드·같은 음의 붙임줄은 유지한다.

- 열린 붙임줄: 다음 음이 없어도 열린 곡선을 표시한다. letRing으로 저장하며 같은 현의 다음 타격 또는 악보 종료까지 여운을 유지한다. 음표 길이와 메트로놈 시간을 늘리지 않는다.
- 슬라이드 아웃: event.slideOut 방향을 저장하고 화음의 각 현에 짧은 사선을 그린다. 목적 음정/시점이 없는 기호이므로 임의 도착음이나 글리산도 음원은 만들지 않는다.
- 괄호 음표: 선택한 음의 parenthesized 표시. TAB 숫자와 오선 음머리에 괄호를 붙이며 그 자체로 재타격을 없애거나 음을 추가하지 않는다. 지속음은 기존 붙임줄과 조합한다.
- 벤드: 선택 현의 note.bendEffect={amount:2,phase}를 저장한다. 올림(up), 유지(hold), 릴리스(release), 왕복(up-release) 모두 full(2반음)이다. 한 음씩만 선택 적용하므로 화음의 다른 현은 변하지 않는다.
- 참고 음원: 올림/릴리스는 작성 음표 길이에 걸쳐 변화, 유지는 full 높이, 왕복은 앞 절반 올림·뒤 절반 내림이다. 원본 이미지에서 세부 연주 시각을 추출한 것은 아니다. 음표 길이를 조절해 각 구간의 시간을 정한다. 일시정지·중간 위치 재생도 벤드 진행도를 유지한다.
- TAB·오선보·혼합 보기, 모바일·데스크톱, 저장/불러오기·실행 취소·다시 실행, 인쇄 렌더러가 같은 데이터를 사용한다. 자연 하모닉스/뮤트와 벤드의 불가능한 조합은 막는다. 건반/드럼 변환 전에는 현악기 전용 표시를 해제하도록 안내한다.

검증: tests/score-extended-techniques.test.mjs와 scripts/verify-extended-techniques.mjs. 브라우저에서 390/1440 화면의 세 보기와 8개 입력 토글, 실행 취소/다시 실행을 검증하고 OfflineAudioContext의 실제 벤드 음높이도 확인한다.
