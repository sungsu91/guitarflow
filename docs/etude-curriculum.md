초급은 각 유형에 처음 들어오는 단계다. 모든 초급 과정이 기타를 처음 잡는 첫날의 과제라는 뜻은 아니다. 레가토 초급 TIP에는 해머온·풀오프 초급을 먼저 익히도록 안내한다. 첫 레가토 과제는 44 BPM, 한 줄 C–D–C, 4분음표, 매 마디 마지막 박의 쉼이다. 중급부터 세 음·8분음표를, 고급부터 연속 16분음표와 여러 줄을 결합한다. 실제 운지 편안함과 숙련도는 사람마다 달라 자동 검사 결과를 전문가 실연 검수로 표현하지 않는다.

## 선택과 이동

연습 유형을 먼저 선택하고 해당 유형의 초급·중급·고급 버튼으로 단계를 선택한다. 유형과 난이도에 전체 옵션을 두지 않는다. 이전·다음은 선택한 조성·유형·난이도·스타일 안에서만 이동하며 끝에서 멈춘다. 과제 번호와 분모도 현재 목록 기준이다. 유형이나 난이도를 바꾸면 첫 과제로 이동하고, 조성 변경은 같은 과제를 조옮김한다.

스타일에는 해당 과정에 실제로 있는 값과 전체만 노출한다. 유형·난이도 변경 후 기존 스타일이 없으면 스타일만 전체로 돌린다. 스타일 때문에 유형·난이도를 몰래 바꾸지 않는다. 모바일은 유형과 3단계 버튼을 항상 보이고 조성·스타일만 접는다. 데스크톱은 같은 상태를 별도 레이아웃으로 표시한다.

## 반주형 아르페지오

아르페지오 6개 과제는 코드 모양을 유지하며 매 마디 첫 박에 루트 베이스와 높은 음을 함께 뜯는다. 중급부터 바레 코드 진행과 루트·5음 교대 베이스, 고급부터 16분 분산음과 세 음 동시 뜯기를 더한다. 코드톤 런은 기존 단음 리드 과정이며 별도로 구분한다. 초급은 C x32010 등 0–3프렛의 기본 오픈 코드, 44/48 BPM의 4분음표부터 시작한다. 초급 아르페지오는 실제 오픈 운지가 준비된 C/D/E/G/A만 제공하며 F/B는 중급부터 제공한다. 조성 변경은 오픈 코드를 평행 이동하지 않고 조성별 실제 코드 사전을 사용한다. C의 두 번째 과제는 C–Am, 중급 첫 과제는 낮은 포지션의 C–Am–F–G이다. 아르페지오에는 전용 핑거스타일 공통 TIP과 p/i/m/a 오른손 예시를 제공한다.

첨부 PDF에서는 코드표와 세로로 겹친 TAB 숫자의 동시 뜯기 방식을 참고했다. 곡의 선율·반주 패턴을 전사하지 않았다. 새 과제는 기본적인 코드 구성음으로 작성했으며 초급의 코드 모양과 조옮김도 함께 검사한다.
