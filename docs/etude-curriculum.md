# FRETIVA 에튀드 유형별 과정

2026-09-13. 9개 유형 × 초급·중급·고급. 87개 독립 과제, 각 8마디의 고정 악보를 제공한다. 조성 선택과 키별 복제본을 없앴다. 각 과제의 음계·조표와 운지는 개별 데이터로 정하며 현재 전 과제는 0–9프렛 안에 있다. 프렛 높이를 난이도로 사용하지 않는다. 과정 순서의 단일 기준은 src/etudes/tracks.js다.

초급은 각 유형에 처음 들어오는 단계다. 모든 초급 과정이 기타를 처음 잡는 첫날의 과제라는 뜻은 아니다. 레가토 초급 TIP에는 해머온·풀오프 초급을 먼저 익히도록 안내한다. 첫 레가토 과제는 44 BPM, 한 줄 C–D–C, 4분음표, 매 마디 마지막 박의 쉼이다. 중급부터 세 음·8분음표를, 고급부터 연속 16분음표와 여러 줄을 결합한다. 실제 운지 편안함과 숙련도는 사람마다 달라 자동 검사 결과를 전문가 실연 검수로 표현하지 않는다.

## 선택과 이동

연습 유형을 먼저 선택하고 해당 유형의 초급·중급·고급 버튼으로 단계를 선택한다. 유형과 난이도에 전체 옵션을 두지 않는다. 이전·다음은 선택한 유형·난이도·스타일 안에서만 이동하며 끝에서 멈춘다. 과제 번호와 분모도 현재 목록 기준이다. 유형이나 난이도를 바꾸면 첫 과제로 이동한다. 같은 과정의 다음 과제는 다른 고정 조성일 수 있다.

스타일에는 해당 과정에 실제로 있는 값과 전체만 노출한다. 유형·난이도 변경 후 기존 스타일이 없으면 스타일만 전체로 돌린다. 스타일 때문에 유형·난이도를 몰래 바꾸지 않는다. 모바일은 유형과 3단계 버튼을 항상 보이고 스타일만 접는다. 데스크톱은 같은 상태를 별도 레이아웃으로 표시한다.

- [Trinity Acoustic Guitar](https://www.trinitycollege.com/qualifications/music/grade-exams/acoustic-guitar): 등급별로 스케일·아르페지오·코드 패턴을 발전시키는 공개 과정 소개를 참고했다.
- 기존 릭 구성 참고: [Berklee Basic Improvisation](https://online.berklee.edu/courses/basic-improvisation), [Guitar Improvisation Techniques](https://online.berklee.edu/courses/guitar-improvisation-techniques).

공개 소개의 진행 원칙을 참고했으며, 원본 악보를 전사하거나 기관의 등급·인증을 앱에 그대로 적용하지 않았다. 모든 새 패턴과 앱 내 난이도는 별도로 설계했다.

- 교육 구조: 27개 과정에 각각 최소 3개, 유형별 고유 순서, 레가토의 한 줄 두 음→세 음→연속 16분 확장, 해머온/풀오프/슬라이드 독립 과정의 기법 일치.
- 탐색: 유형·난이도 변경, 스타일 교집합, 목록 순서·분모·이전/다음 경계, 다른 과정으로의 이동 거부.

## 반주형 아르페지오

아르페지오 9개 과제는 코드 모양을 유지하며 매 마디 첫 박에 루트 베이스와 높은 음을 함께 뜯는다. 초급은 기본 C x32010과 C–Am 전환, 중급 첫 과제는 C–Am–F–G이다. 중급 두 번째 과제는 Bmaj7 x24342(2–4) → D#m x68876(6–8) → Emaj7 x79897(7–9) → Em7 x79787(7–9) 이동이다. Bmaj7/Emaj7은 같은 모양을 옮기고, Emaj7/Em7은 바레를 유지하며 안쪽 두 음을 낮춘다. 7→2프렛으로 돌아오는 이동도 미리 준비한다. Em7은 B장조의 기본 코드가 아닌 차용화음이므로 G·D 제자리표를 검증한다.

이 코드 이동 자체는 중급이다. 고급 과제는 동일한 코드표와 이동을 유지한 상태에서 매 박 교대 베이스와 16분 높은 음을 제어하고, 세 음 동시 뜯기·쉼 뒤 재진입·8분/16분 전환을 결합한다. 높은 프렛이나 빠른 BPM만으로 단계가 올라가지 않는다. 코드톤 런은 별도의 단음 리드 과정이다. 아르페지오에는 전용 핑거스타일 TIP과 p/i/m/a 예시를 제공한다.

첨부 PDF에서는 코드표와 세로로 겹친 TAB 숫자의 동시 뜯기 방식을 참고했다. 곡의 선율·반주 패턴을 전사하지 않았다. 새 과제는 기본적인 코드 구성음으로 작성했으며 각 코드표의 모든 구성음·TAB·임시표를 함께 검사한다.
