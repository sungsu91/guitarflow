# FRETIVA 에튀드 커리큘럼

2026-09-09. 초급 12개·중급 13개·고급 12개, 독립 패턴 37개. 각 8마디이며 C/D/E/F/G/A/B 조성으로 259개 악보를 제공한다. 조옮김을 별도 패턴으로 세지 않는다. 이 과정은 단선율 리드 기타 연습 과정이며 코드 스트러밍·청음 등 기타 교육 전체를 대체하지 않는다.

## 공개 자료에서 참고한 진행 원칙

- [Berklee Basic Improvisation](https://online.berklee.edu/courses/basic-improvisation): 적은 음으로 주고받는 프레이즈, 리듬·선율 동기의 반복과 변형, 이후 코드톤과 연결을 다룬다. 이 과정에서는 초급 후반의 짧은 훅과 응답, 중급의 코드 도착음에 적용했다. 이 강좌 자체는 악기 학습 경험을 요구하므로 강좌의 Level 1을 앱의 기타 입문 등급으로 그대로 옮기지 않았다.
- [Berklee Guitar Improvisation Techniques](https://online.berklee.edu/courses/guitar-improvisation-techniques): 포지션 간 연결, 주제와 변형, 트라이어드·7화음의 응용을 다룬다. 앱에서는 중급 포지션 연결부터 고급 복합 음형으로 확장하는 구조에 참고했다.
- [JustinGuitar Beginner](https://www.justinguitar.com/beginner): 초급 과정에도 리드 기타와 블루스 스타일을 포함한다. 초급을 무조건 음계 왕복만으로 구성하지 않는 방향에 참고했다.

확인한 범위는 공개 과정 소개와 강의계획이다. 유료 강의를 수강하거나 원본 악보를 전사한 것이 아니다. 아래 등급과 음표·리듬은 FRETIVA에서 별도로 구성한 것이며 위 기관의 인증이나 동일 과정이 아니다.

## 순서

| 단계 | 초급 | 중급 | 고급 |
|---|---|---|---|
| 01 | 4분음표 트라이어드 | 슬라이드로 포지션 연결 | 16분음표 포지션 이동 |
| 02 | 두 음으로 질문과 대답 | 펜타토닉 포지션 왕복 | 연속 3도 16분음표 |
| 03 | 4·8분음표 리듬 릭 | 3도 교차 대화 | 4도 크로스 16분음표 |
| 04 | 3도로 맺는 팝 프레이즈 | 기준음으로 돌아오는 피벗 | 16분 피벗 음역 확장 |
| 05 | 스케일 줄 왕복 | 두 옥타브 트라이어드 | 펜타토닉 네 음 시퀀스 |
| 06 | 상행·하행 릭 | 4도 줄 건너뛰기 | 트라이어드 역방향 엔진 |
| 07 | 두 음 해머온 | 엇박에 들어오는 펜타토닉 | 메이저7 지그재그 연결 |
| 08 | 하행 풀오프 릭 | 코드톤 포지션 연결 릭 | 블루 노트 급가속 응답 |
| 09 | 펜타토닉 반복 훅 | 재즈 메이저7 아르페지오 | 8분·16분 밀도 전환 |
| 10 | 쉼이 있는 발라드 멜로디 | 짧게 달리고 길게 맺기 | 엇박 16분 시퀀스 |
| 11 | 블루 노트 왕복 릭 | 해머·풀·슬라이드 혼합 릭 | 세 기법 연속 레가토 |
| 12 | 반복·변형 미니 솔로 | 질문·엇박·응답 솔로 | 시퀀스·도약 종합 솔로 |

초급 1–4는 긴 음과 일정한 박, 5–8은 음형과 기본 기법, 9–12는 쉼·반복·도착음으로 짧은 문장을 만드는 단계다. 초급의 쉬운 과제는 입문자가 성공 경험을 얻는 데 필요하다. 중급은 속도만 올리기보다 포지션·도약·약박 진입·화음 인식을 늘린다. 고급은 이 단선율 커리큘럼 내 상위 테크닉 단계로, 지속적인 16분음표에서 도약·줄 이동·기법 전환을 결합한다. 전문 재즈 즉흥 능력 전반을 뜻하지 않는다.

## 연습 방법

TIP의 권장 BPM에서 2마디 → 4마디 → 8마디로 연결한다. 느린 템포에서도 음 길이, 쉼표의 뮤트, H/P/SL 도착 시점을 지킨다. 같은 리듬의 질문과 응답이 어떻게 달라지는지 들어 본다. 템포를 올리는 것만을 완료 기준으로 삼지 않는다.

쉼표는 오선보에 표시하고 타브에는 음을 인쇄하지 않는다. 중급 코드톤 과제는 조성에 맞춰 코드명도 조옮김한다. 메트로놈은 클릭만 제공하며 코드 반주나 악보 재생을 제공하지 않는다. 고급에서도 무작위 프렛 배정은 하지 않는다. 같은 줄 기법의 방향과 줄 변경 피킹을 명시한다.

이전·다음은 현재 난이도와 조성 안에서 선택한 연습 유형·스타일에 해당하는 악보만 이동한다. 카운터도 해당 목록 기준이다(중급 스케일 1/3). 필터를 전체로 바꾸면 해당 범위의 전체 목록으로 돌아간다. 초급·고급은 12번, 중급은 13번에서 정지하며 다음 등급으로 자동 이동하지 않는다.

## 검증 범위

37개 음형/리듬의 중복 여부, 259개 악보의 마디 길이·음계·기보/TAB 대응·기법 연결, 이동 폭, 으뜸음 종지, 코드톤 과제의 첫 음을 검사한다. 1008개 화면 조건의 SVG 검사와 쉼표·코드명·기법 라벨 검사를 수행했다. 음악적 표현력이나 손에 맞는 난이도는 코드 검사만으로 인증할 수 없으며, 실제 연주자의 피드백으로 조정할 수 있다.

공통 TIP은 별도 펼침 패널에서 D/U 방향, 일정한 8분·16분음표의 얼터네이트 피킹, 쉼표와 레가토 예외, 뮤트·음량·프레이징·구간 반복을 설명한다. 예시는 교육용 기본 방향이며 전체 악보의 모든 음에 피킹을 지정하는 것은 아니다. 중급 8은 16분 접근음과 8분·4분 도착음, 대각선 포지션 이동을 결합해 연주 부담도 중급으로 보강했다.

중급 13: 코드 잡고 줄 나누어 뜯기. 연습 유형 ‘코드 아르페지오’에서 선택한다. I–vi–IV–V–I–vi–V–I 진행, 마디별 코드표와 실제 TAB 운지의 일치를 검사한다. 코드음을 겹쳐 울리는 핑거피킹 반주 예제이며 이동형 바레 코드를 사용한다. 악보는 발음 시작 시점 중심으로 기보하고, 음의 겹침은 과제 TIP으로 안내한다. 동시에 여러 줄을 뜯는 화음 이벤트나 원본 곡 전사는 이번 예제에 포함하지 않는다.
