# 독립 리듬 가이드실

- 보관함/연습 화면 우측 가이드실. 연습 화면에서 열면 복제한 핵심 패턴을 선택한다.
- 기존 연습 DOM과 스크롤을 보존하고 재생은 일시정지한다. 닫을 때 자동 재생하지 않는다.
- 기본 기둥·빔 방향은 위. 기존 방향 설정은 이번 기본값 변경에서 한 번 위로 정리되며 이후 사용자가 아래로 선택한 값은 유지한다.
- 바깥 유형/패턴 버튼만 편집 선택 역할을 한다. 가이드 악보는 읽기 전용이다.
- `guideModel.js`의 음가 데이터를 악보, 등간격 분할 칸, 설명, 오디오 이벤트가 공유한다. 치기/앞 음 유지/쉼을 구분하고 이음줄의 후속 음은 재타격하지 않는다.
- 2/4·3/4·4/4: 4분음표 BPM. 6/8·9/8·12/8: 점4분음표 BPM, 각각 2·3·4개의 큰 박. 6/8의 보통 8분음표 세 개는 연음 숫자를 붙이지 않는다. 복합박자 셋잇단 예제는 4분 구간의 셋잇단 뒤에 보통 8분음표를 둔다.
- 가이드는 별도 카운트인 없이 선택 패턴을 반복한다. 기준 박 소리는 기존 설정을 공유한다. 치는 소리/BPM은 연습 설정에서 초기화하고 가이드 내 변경은 원본 악보에 저장하지 않는다.
- 일반 휴대폰에서 한 박 가이드와 6/8 두 큰 박은 조작부와 함께 보인다. 긴 핵심 패턴/9·12/8은 본문만 스크롤하며 조작부는 고정한다.

## 검증

`node --test tests/rhythm-guide.test.mjs tests/rhythm-trainer.test.mjs tests/rhythm-packs.test.mjs tests/rhythm-count-in.test.mjs`

390×844 모바일 브라우저: 8·16·16은 치기/유지/치기/치기, 16·8·16은 치기/치기/유지/치기, 쉼표는 별도 × 표시. 6/8 3+3 두 큰 박과 점4분 기준 표시, 3·6·7연음의 실제 표기와 재생 중 칸 강조/진행선을 확인했다. 원래 연습 스크롤 201px로 복귀하고 일시정지 상태가 유지되는 것을 확인했다.
