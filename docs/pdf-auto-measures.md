# PDF 마디 자동 인식 (layout-7)

## 범위

마디 위치만 검출한다. 음표·운지·코드·리듬·반복 기호를 OCR로 해석하지 않는다. 원본 PDF는 변경하지 않으며, 기존 `barMap`과 연습 재생 엔진을 공유한다. 데스크톱과 모바일의 표시 컴포넌트는 분리한다.

## 검출

- PDF.js 원본 이미지 경로로 3.5배와 3배에서 분석한다. 분석용 네이티브 이미지 축소를 끄고 렌더 완료 후 Worker로 전달한다.
- 긴 수평선의 간격과 범위를 검사한다. 4·5·6줄뿐 아니라 7·8줄도 허용한다. 1줄 타악기 보표는 수평선 양쪽으로 뻗은 마디선으로 별도 검출한다. 음표 기둥과 작은 코드 다이어그램은 제외한다.
- 짧은 마지막 보표는 다른 줄의 왼쪽 위치와 선 간격을 참조하되, 오른쪽 끝을 페이지 너비로 늘리지 않는다. 종지 복선은 한 경계로 묶고 짧은 마지막 마디도 보존한다.
- 보표 사이를 실제로 연결하는 왼쪽 세로선/괄호 또는 마디선이 있으면 하나의 동시 연주 묶음으로 처리한다. 가까운 거리나 같은 마디 폭만으로 순차적인 줄을 합치지 않는다. 같은 번호의 하이라이트는 위아래 보표를 함께 덮는다.
- 다른 렌더 크기에서 연결 보표가 복구되면 분리된 줄 대신 연결된 결과를 사용한다. 그 외에는 주 렌더의 경계를 보존하며 빠진 줄만 보완한다.
- 전체 페이지 순서, 위에서 아래, 왼쪽에서 오른쪽으로 번호를 매긴다. 마디 개수나 너비를 4개 균등 분할로 가정하지 않는다.

마디 경계가 불확실하면 검토 표시를 남긴다. confidence는 통계적인 정확도 확률이 아니다. 기울어진 사진, 깨진 연결선, 매우 작은 다단 악보와 선이 심하게 소실된 스캔까지 검증한 것은 아니다. 연결선 없이 여러 파트가 나란히 있는 악보는 순차 보표와 구별할 추가 정보가 필요하다.

## 조작

1. `마디 자동 인식`을 누르면 확인창을 표시한다. 기존 설정이 있으면 교체 시점을 설명한다.
2. 분석 결과 화면의 작업 버튼은 `완료`, `취소` 두 개이다. 적용 후 수정·새로 분석·분석 초기화·개발 디버그 선택 UI는 제거했다.
3. `완료` 클릭에서 마디 설정을 저장하고 첫 페이지/첫 마디부터 메트로놈을 시작한다. 오디오 활성화는 클릭 이벤트에서 유지한다. 브라우저가 오디오를 시작하지 못하면 기존 오류 안내를 표시한다.
4. 확인창이나 미리보기에서 취소하면 기존 마디 설정을 바꾸지 않는다.
5. `마디 영역 초기화`도 확인창을 거친다. 마디 영역·연습 순서·반복 범위를 지우고 원본 PDF·필기·여백은 유지한다. 기존 편집 이력으로 되돌릴 수 있다.
6. 일반 수동 편집은 별도로 유지하고, 내장 연습실에서도 편집 완료 버튼으로 빠져나온다.
7. 악보 선택창 내부에 `파일 불러오기`를 추가했다. 데스크톱과 모바일 모두 기존 PDF 불러오기/정보 확인/기기 저장 흐름을 사용한다.
