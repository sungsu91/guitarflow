# 내 악보: 메트로놈 중심 연습과 공용 백킹 패널

## 적용
- 생성 악보 열람 화면 `EditablePractice`의 악보 위에 `PracticeTransport`를 배치했다. 박자 원형 표시, 연습 BPM, 시작/일시정지/재개/정지와 클릭 음소거를 제공한다.
- 악보 소리는 기본 꺼짐이다. 기타/피아노는 보조 옵션으로 남기고 클릭 음소거와 별도로 제어한다. 연습 BPM과 악보 소리 선택은 해당 화면의 상태이며 저장 문서나 에튀드 설정에 쓰지 않는다.
- `ScorePlayback`과 `useEtudeMetronome`의 기존 AudioContext/오디오 시계를 재사용한다. 클릭 시작 시각을 기준으로 진행바와 박자 표시를 계산한다. 다른 시작 버튼이나 두 번째 연습 엔진은 만들지 않았다.
- 연습 중 악보 소리나 음색 변경은 음원 출력만 교체한다. 현재 오디오 시각에서 기존 `voicesFrom`을 사용해 이어지며 클릭/진행바 시계는 그대로 유지한다. 비동기 음색 로딩은 세션/요청 버전으로 보호한다.
- 공용 `PracticeBeatDots`를 에튀드 이동형 메트로놈과 내 악보 연습에 함께 사용한다.
- `scoreMeters`와 기존 반복 순서를 사용하여 마디 길이, 클릭 간격, 첫 박 강조, 진행바 좌표를 맞춘다. 마디별 `meter` 정보가 있다면 해당 마디부터 적용하며 반복 시 원래 마디의 박자표로 돌아간다. 기존 편집기의 박자 입력 UI를 새로 만들거나 저장 악보에 박자 변경을 임의로 추가하지 않았다.
- `PracticeBackingPanel`로 에튀드의 패널/손잡이를 공용화했다. 기존 BackingLoop 플레이어, 재생목록, 음량, 반복, 음원 및 activityRegistry를 그대로 사용한다. 우측 손잡이 위치 저장 키는 에튀드와 내 악보를 분리했다.
- 패널 접기는 재생 정지와 분리되며 재생 중 표시가 남는다. 악보 소리를 꺼도 백킹을 사용할 수 있다. 백킹과 연습의 자동 BPM 동기화는 추가하지 않았다.
- 화면을 벗어나면 기존 cleanup 정책으로 이전 연습과 백킹을 정리한다. 편집·저장 기능과 테마는 유지했다.

## 검증
- 빌드 통과(기존 번들 크기 경고 있음).
- 관련 단위 테스트 37개 통과. 점음표, 쉼표, 셋잇단음표, 음 길이 수정, 반복 방문, 가변 박자표의 누적 tick과 클릭 계획을 포함한다.
- `verify-saved-practice.mjs`: 화이트/골드 다크, 모바일/데스크톱에서 검증. 기본 무음 연습에서 악기 소스가 시작되지 않음, 클릭 음소거의 실제 gain이 0으로 내려가는 동안 진행바/박자 표시 유지, 기타→피아노 전환, 소리 끄기 후 새 악기 소스가 생성되지 않음, 일시정지·재개, BPM 변경, 4/4→3/4→6/8→반복 후 4/4 복귀 확인.
- AudioContext에 예약한 실제 클릭 시작 시각과 주파수를 검증했다. 240 BPM에서 4/4·3/4 클릭은 0.25초 간격, 6/8 클릭은 0.125초 간격이고 각 마디 첫 클릭은 강조된다. 진행바 위치도 같은 AudioContext의 시각과 비교했다.
- 백킹 재생 중 패널 접기, 악보 소리 꺼짐 상태의 동시 연습, 에튀드 이동 후 이전 백킹 정리와 단일 컨트롤러 확인. 브라우저 런타임 오류 없음.
- 기존 에튀드 진행바 및 별도 리듬/반복 브라우저 회귀 테스트도 통과.
- 테스트 악보는 격리된 브라우저 저장소에만 생성했으며 앱 카탈로그나 사용자의 저장 악보에는 추가하지 않았다.

결과와 화면 캡처: `artifacts/saved-practice/`.
