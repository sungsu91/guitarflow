# 다시 피어나는 밤 — 제작·검토 기록

기존 오리지널 네 곡을 유지하고 다섯 번째 독립 악보로 추가했다. 개발서버의 **악보연습실 → 연습 유형 → 아르페지오 → 난이도 4.0 / 5**에서 선택하거나 제목으로 검색한다. A단조, 4/4, BPM 72, 표준 튜닝, 카포 없음이다.

## 구성과 실제 음표

- 기보 40마디, 연주 순서 `1–16 → 17–24 → 17–24 → 25–40`로 48마디다.
- 기본 재생은 160초이며 끝나면 멈춘다. 마지막 화음에는 자연 감쇠를 위한 1.8초를 추가로 확보했다.
- 도입 I는 정확히 `8분·8분·4분`을 두 번 연주하는 단일 성부다. 낮은 2번 줄 선율은 각 구간의 둘째 박에 나타난다.
- 5–12마디 V는 2번 줄의 2분음표 선율과 4·3·4번 줄의 반주를 분리했다. 1–12마디에는 1번 줄 음이 없다.
- 13–16마디의 U는 1번 줄의 F4→G4→A4→B4로 상승한다. 16마디 끝에 쉼이나 페이드아웃을 추가하지 않았다.
- H는 중간 두 줄을 실제 동시음으로 울린다. L인 **17·29·34마디는 1번 줄을 첫 박에 한 번만 연주해 4박 유지**하고, 3박에는 베이스만 다시 뜯는다.
- 33마디 C5→D5에서 34마디 **E5(1번 줄 12프렛)**로 올라간다. 반주의 13·14프렛도 두 자리 숫자로 기보한다.
- 39마디 뒤 2박은 다시 2번 줄 C4로 내려간다. 40마디는 **5번 0·4번 2·3번 2·2번 1프렛**만 동시에 온음표로 울리며 1번 줄을 추가하지 않는다.
- 각 성부는 독립적으로 마디당 4박이다. 손가락 번호나 자동 스트럼은 넣지 않았다.

## 실제 발음하는 화음 검토

- C/E의 첫 베이스는 4번 줄 2프렛 E3다.
- Dm/F의 베이스는 요청한 4번 줄 3프렛 F3이며, 패턴에서 D·F·A가 실제로 포함된다. 일반 Dm으로 교체하지 않았다.
- 낮은 E7sus4→E7: 3번 줄 **2→1프렛(A3→G♯3)**. 2번 줄 3프렛 D4가 유지돼 두 코드 모두 7음이 포함된다.
- 높은 E7sus4→E7: 2번 줄 **10→9프렛(A4→G♯4)**. 3번 줄 7프렛 D4가 반주에 포함된다.
- 27마디 B7에는 3번 줄 8프렛 D♯4가 실제로 들어 있다. 28마디의 Em7은 2번 줄 8프렛 G4, 뒤의 E7은 9프렛 G♯4다. 29마디 Am으로 해결된다.
- Am높음과 Am정점의 베이스는 모두 **5번 줄 개방현 A2**다. 높은 포지션으로 베이스를 옮기지 않았다.
- 같은 줄의 새 타격은 앞 음을 종료한다. 반주는 같은 줄의 재타격 또는 현재 운지 해제까지만 유지하며, 코드 전환을 넘어 이전 프렛을 계속 울리지 않는다.

## 이동을 위해 수정한 음길이

음높이와 타격 시작 위치는 유지했다. 아래 구간의 **마지막 반주 8분음표만 16분음표+16분쉼표**로 바꿨다. BPM 72에서 마지막 약 208ms 동안 반주 운지를 풀 수 있다. 상성부의 멜로디는 유지되므로 전체 소리가 멈추지는 않는다. 17·29·34마디의 온음표 멜로디도 줄이거나 재타격하지 않았다.

| 18·30 | 3–4박 | Em7높음→F중간, 하행 이동 |
| 19·31 | 1–2박, 3–4박 | F중간→C중간→Dm중간, 두 번의 포지션 이동 |

총 20개 2박 구간의 반주 말미를 조정했다. 각 운지는 눌린 프렛 사이가 최대 3프렛 범위이며 바레/부분 바레를 이용하는 형태다. 개방현 A를 울리는 하이코드에서는 5번 줄을 바레로 누르지 않아야 한다. 34마디의 12–14프렛 접근성과 긴 멜로디를 유지한 상태에서의 이동은 기타의 넥·몸통 구조 및 연주자에 따라 달라진다. **이는 운지 데이터와 악보상의 검토이며 실제 기타 실연을 한 결과가 아니다.**

## 강약과 소리의 흐름

악보에 p, mp, mf, f, cresc., dim.과 두 번째 후렴의 강화 지시를 표시했다. 표기만 추가한 것이 아니라, 실제 재생 음마다 velocity와 반복 회차별 강약을 저장했다.

- 도입 선율 강도 0.33–0.36 → A파트 0.52–0.60 → 상승 구간 0.62–0.74.
- 첫 후렴 0.78–0.83, 두 번째 방문은 각각 0.045 증가한다.
- 연결부는 0.66→0.69→0.73→0.77로 다시 쌓는다.
- 마지막 후렴 0.87에서 올라가 **34마디 1.0**을 정점으로 한다. 35–40마디는 점차 내려간다.
- V/U의 가운데 반주는 선율 강도의 39%, H/L은 43%, 베이스는 70%다. 동시음 수에 따른 출력 정규화도 적용된다.

실제 앱의 기타 합성기로 만든 WAV의 신호 측정 결과:

| --- | ---: |
| 도입 | 0.00500 |
| A | 0.00687 |
| 상승 | 0.00783 |
| 첫 후렴 1회 | 0.00896 |

17마디 첫 방문은 0.00911로 12마디의 0.00788보다 커졌고, 34마디는 0.01273으로 전체 48번 마디 방문 중 최대 RMS였다. 피크 절댓값은 0.10743으로 클리핑이 없다. 진행이 끝나는 160초 이후에도 마지막 잔향이 남고 감쇠한다. 이러한 수치는 **사람이 듣는 음색·프레이징·균형 평가를 대신하지 않는다.**

## 검증과 산출물

- 구조 검사: 음정·줄/프렛·성부별 박자·L의 단일 타격·sus4 해결·반복·저음 종지·강약·저장/재로드 통과.
- 화면 검사: 320·390·412·1440px에서 TAB 가로 잘림과 코드·반복·강약 표기와 음표 충돌이 없음을 확인했다. 10·12·13·14프렛을 포함한 모바일 이미지를 직접 확인했다.
- 동시음 정렬: 온음표와 8분음표의 서로 다른 음표 머리 폭 때문에 TAB 열이 어긋나던 공통 렌더러를 수정했다. 같은 시작 시점의 성부들이 하나의 TAB 중심선을 공유한다.
- 단일 성부 도입 뒤에 다성부가 나오는 경우에도 도입의 리듬 기둥이 표시되도록 수정했다.
- TAB/오선/병기 3가지 모드에서 새 곡과 기존 「빛이 머무는 자리」의 렌더링을 확인했다.
- 전체 자동 테스트 1,459개 통과. 최종 정렬 수정 후 관련 54개 회귀 검사와 빌드 통과.
- **실제 청음: 미수행. 실제 기타 연주: 미수행.**

청음용 파일: `work/night-blooms-again/night-blooms-again-preview.wav`.

## 실제 브라우저 전곡 재생 완료 기록

BPM 72로 **160초 전곡 재생**을 수행했다. 요청한 48회 마디 방문, 550개 음의 실제 Web Audio 시작 예약, 후렴 반복 후 25마디 이동, 40마디 후 정지와 자동 처음 반복 없음이 확인됐다. 진행 포인터 3,998개 표본에서 오디오 시계와의 최대 시간차는 약 **10.7ms**였다. 이는 브라우저 재생·스케줄·화면 추적 검증이며 청음 검증은 아니다.

원시 기록은 `work/night-blooms-again/full-playback.json`, 요약은 `playback-summary.json`이다. 편집 가능한 악보 원본은 `work/night-blooms-again/night-blooms-again.fretiva.json`에 별도로 내보냈다.

## 악보 표시 후속 수정

사용자 요청에 따라 `p`, `mp`, `mf`, `f`, `cresc.`, `dim.` 등 강약 텍스트를 악보에서 제거했다. 이벤트의 velocity 및 반복별 강약은 그대로여서 재생의 표현은 유지된다. 위의 강약 표기 화면 검사는 제거 전 기록이다.

각 마디의 작곡용 운지 데이터를 사용해 코드표를 부착했다. 2박마다 운지가 바뀌면 1박·3박을 구분하며, 같은 코드라도 다른 포지션은 별도 코드표로 표시한다. 34마디의 Am은 개방 A와 12–14프렛을 함께 표시한다. 코드명·코드표는 해당 마디 음표 위에 배치하고, 모바일에서는 많은 코드표가 줄바꿈된다. 검증 기록과 화면은 `work/measure-chord-charts/`에 있다.
