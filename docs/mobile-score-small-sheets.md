# 모바일 악보 제작 메뉴 정리

- 하단 `메뉴`와 모바일의 메뉴/음표/마디/곡 정보 탭 패널을 제거했다. 데스크톱 문서 메뉴는 유지한다.
- 마지막 입력 줄은 `마디 추가 · 두 자리 · 3연음`이다. 음 길이 줄에 있던 3연음 버튼은 제거하여 한 곳에서만 조작한다.
- 상단 `악보 편집` 제목을 누르면 작은 악보 설정 시트가 열린다. 곡 제목, 박자표, 조표, 기본 BPM, 보표 보기, TAB 리듬 표시만 넣었다.
- 실제 음표를 직접 누르면 선택 음 속성 시트가 열린다. 빔 자동/이전과 연결/여기서 끊기를 제공하고 기존 주법과 3연음 묶음 도구는 작은 접힘 영역에 유지한다. 빈 슬롯이나 쉼표 선택 시에는 열리지 않는다.
- 시트는 입력 패널 쪽 화면 하단에 겹쳐 표시하며 악보의 높이와 스크롤을 바꾸지 않는다. 바깥 누르기, 닫기, Esc로 닫을 수 있다. 열고 닫는 동안 음표 데이터나 선택 위치를 초기화하지 않는다.
- 문서 변경과 빔/3연음 명령, 저장, 실행 기록은 기존 공유 로직을 사용한다. 별도 모바일 악보 데이터를 만들지 않았다.

## 변경 파일

- `src/etudes/ScoreEditor.jsx`: 모바일 메뉴 렌더링 제거, 제목/음표 선택과 작은 시트 연결.
- `src/etudes/MobileScoreInput.jsx`: 하단 메뉴 제거 및 3연음 이동.
- `src/etudes/MobileScoreSheets.jsx`: 모바일 전용 설정/선택 음 시트.
- `src/etudes/mobileScoreSheets.css`: 시트의 크기, 정렬, 모바일 타이포그래피.
- `src/etudes/scoreEditor.css`: 사용하지 않는 대형 패널 스타일 제거.
- `scripts/verify-mobile-score-sheets.mjs`: 신규 브라우저 검증.
- `scripts/verify-beam-overrides.mjs`, `scripts/verify-score-triplets.mjs`: 새 모바일 진입 동선으로 검증 스크립트 갱신.
