# 리듬 트레이너 기본 제공 연습팩

2026-09-25 구현. 특정 개수에 맞추지 않고 대표 음가 조합·쉼표 위치·연음·이음줄의 누락 여부를 검토해 구성했다. 현재 **55팩 / 485마디**, 서로 다른 핵심 패턴 55종이다. 팩마다 8~9마디를 제공한다.

## 구성 및 검증

- 핵심 패턴은 1박·2박·4박을 보존한다. 보관함에는 핵심 패턴 자체를 표시한다.
- 연습은 핵심 제시, 간격을 둔 반복, 박 위치 이동, 주변 음가 및 쉼표 변경 순서로 구성한다. 한 마디 핵심은 순환 배치와 쉼표 대체를 연습한다.
- 초급 4팩, 중급 20팩, 고급 31팩. 전체 팩은 4/4이며 사용자 악보는 2/4·3/4·4/4를 지원한다.
- 공유 리듬 데이터가 SVG 악보, 실제 음가, Web Audio 예약 시각, 강조, 진행선을 결정한다.
- 저장 형식의 12 tick/4분음표는 유지하고 내부 음가 합산은 420단위/4분음표 정수 격자로 검증한다. 기존 저장 자료는 그대로 읽힌다.
- 3:2는 8분음표 3개=1박, 16분음표 3개=반 박. 5:4·6:4·7:4는 16분음표 5·6·7개=1박이다. 빔은 표기 음가를, 재생은 비율 적용 후 길이를 따른다. 쉼표를 포함하는 연음도 괄호 범위를 유지한다.
- 기본 팩 편집은 새 ID의 사용자 사본을 만든다. 빈 악보 생성, 핵심 길이 지정, 핵심/연습 마디 개별 편집, 브라우저 로컬 저장을 지원한다. 원본 카탈로그는 변경되지 않는다.
- 이음줄은 다음 박/마디의 첫 음을 재타격하지 않는다. 현재 음색은 타악기이므로 음의 감쇠를 인위적으로 길게 늘이지 않는다.

### 참고 이미지 대응

사용자 확인에 따라 중복을 제외한 6종을 참고했다. 가려진 외부 악보 전체를 추정 전사하지 않고 핵심 패턴을 보존한 새 연습을 구성했다.

| 참고 | 핵심 | 팩 |
|---|---|---|
| reference-eighth-sixteenths | 1박 | 8분 + 16분 + 16분 |
| reference-rest-three | 1박 | 16분쉼표 뒤 세 음 |
| reference-triplet-tail | 1박 | 8분 뒤 촘촘한 셋잇단 |
| reference-paired | 2박 | 8·16·16 → 쉼·16·8 |
| reference-six | 1박 | 6잇단 · 균등 분할 |
| reference-seven | 1박 | 7잇단 · 균등 분할 |

이미지 1·2: 16분쉼표+16분×3. 이미지 3: 8분+반 박의 16분 셋잇단. 이미지 4: 6잇단. 이미지 5·6·9: 7잇단. 이미지 7: 8·16·16과 쉼16·16·8의 두 박 조합. 이미지 8: 8·16·16.

### 확인 결과

- `node --test tests/rhythm-trainer.test.mjs tests/rhythm-packs.test.mjs`: 21개 통과.
- 전 팩의 핵심/마디 음가, 중복 핵심 없음, 난이도 범위, 학습 단계와 변형, 이음줄, 기존 저장 호환 검증.
- 전 55팩을 BPM 30·73·120·240에서 두 번 반복하며 기대 발음 시각과 예약 시각 대조. 쉼표/이음줄 연속음은 발음하지 않음.
- 모든 음표·쉼표의 시작과 중간 시점에서 강조 대상 및 진행선 좌표 대조.
- `work/rhythm-pack-audio-check.html`: 브라우저 OfflineAudioContext 실제 PCM으로 3·5·6·7잇단 × wood/rim/clap 12조합 통과. 발음 구간 에너지와 쉼표 구간 무음을 확인.
- 모바일 390×844와 데스크톱 1440×1000에서 악보 및 재생 UI 확인. 모바일에서 최소 5마디가 한 화면에 표시됨.
- 핵심 패턴 사본 편집, 연음 중 쉼표 전환 및 취소 복원 확인. 저장 직렬화/복원과 원본 불변은 자동 검사.
- `npm run build` 통과.

연음 비율의 기보 기준: [LilyPond 공식 기보 문서](https://lilypond.org/doc/v2.27/Documentation/notation/writing-rhythms), [Dorico 공식 연음 입력 문서](https://www.steinberg.help/r/dorico-se/6.2/en/dorico/topics/write_mode/write_mode_note_input/write_mode_tuplets_popover_r.html).
