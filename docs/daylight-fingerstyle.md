# 햇살 사이로 · A Little Further

92 BPM · 4/4 · C major / A minor · Melodic Fingerstyle / Light Groove.

독립 샘플 1개를 추가했다. 기존 Still Walking Together 데이터와 UI·재생 엔진은 바꾸지 않았다. 에튀드의 연습 유형 → 악보 검색에서 **A Little Further**로 찾을 수 있다.

## 길이와 반복

원래 모든 파트 길이를 더하면 재생 70마디다. 사용자가 선택한 압축안은 **작성 40마디 / 재생 56마디, 약 2분 26초**다. Verse A와 Chorus는 각각 8마디를 한 번만 기보하고 도돌이로 총 두 번 연주한다. Pre 2는 별도 2마디의 변형 응답이다. D.S./D.C./Coda 및 1·2번 엔딩은 사용하지 않는다.

## 화음과 멜로디

- 첫 박마다 두 손가락으로 뜯는 규칙을 적용하지 않았다. 멜로디 선행, 베이스 단독, 베이스+멜로디, 세 음 pinch를 프레이즈에 맞게 배치했다.
- 화음은 첫 박에만 있지 않다. 후렴 중간 박에도 3+1, 3+2, 4+2번줄 등의 두 음 응답을 넣었다. 긴 멜로디와 안쪽의 짧은 16분음표를 교대하며 단순 스트럼·컨트리식 교대 베이스를 피했다.
- Verse A는 짧은 쉼과 4분 유지음, Pre는 빠른 화성 변화, Chorus는 8–16–16 / 16–8–16 / 16–16–8 / 8–8의 질문·응답을 사용한다. Final은 같은 리듬 정체성을 높은 음역으로 확장한다.
- 13·15·29·31마디의 첫 베이스/멜로디는 let ring으로 다른 현의 반주 아래에 유지된다. 같은 현의 다음 피킹에서 교체되고 반복 이동을 가로질러 무제한 유지되지 않는다.
- Verse B 23–24마디 실제 최저음은 **A2→G2→F2→E2**다. Fmaj7은 낮은 F를 추가한 보이싱으로, 저음을 엄지로 잡거나 부분 바레를 사용한다.
- Final 29–36마디는 5–10프렛으로 확장했다. Cadd9의 높은 D를 위해 10프렛을 사용한다. Cadd9는 8프렛 바레+10/9/10, G/B는 7프렛 바레+9/8, Am7은 5프렛 바레+8로 잡을 수 있다. 누르는 프렛 간 차이는 최대 3프렛이다.
- B7은 x21202의 B–D#–A–B–F#가 실제로 울린다. 베이스 단독과 짧은 쉼 뒤의 화음으로 강세를 바꾼다. 다음 E7의 G#·D가 긴장을 이어받아 Am7 또는 Fmaj7로 연결된다.
- **Esus4→E7:** 2마디 3박→4박에서 3번줄 2→1. **Gsus4→G:** 12·28마디 4박의 앞/뒤 8분음표, 39마디 3박에서 2번줄 1→0.
- Outro는 템포를 유지하고 마지막 두 마디에서 밀도를 낮춘다. 마지막은 C 베이스→E/G→D/E를 뜯고 두 박을 let ring으로 남긴다. H/P/Slide는 프레이즈에 필요하지 않아 억지로 추가하지 않았다.

첫 박 구성: 1음 시작 12마디, 2음 시작 26마디, 3음 시작 2마디.

첫 Chorus 마디별 최고음: E4–G4–G4–E4–E4–E4–G4–E4.

Final 마디별 최고음: D5–B4–C5–B4–A4–C5–B4–D5.

최고음은 각 마디의 피치 범위를 뜻한다. 실제 선율은 1·2번줄의 리듬까지 함께 따른다.

## 검증 결과와 한계

- 새 샘플·이전 샘플·반복·마디 이동·잔향·모바일 크기 관련 자동 테스트 **46개 통과**. 프로덕션 빌드 통과(번들 크기 경고는 남아 있음).
- 코드 엔진 `CHORD_TONE_INTERVALS` 기준으로 모든 보이싱 및 각 화성 구간에서 실제 울리는 음의 집합을 검사했다. slash bass, B7/E7, sus4, add9, maj7, 6 포함.
- 모든 마디 1920 ticks=4박, 코드 전환 시점, 8/16분 mixed beam의 박 단위 그룹, 명시적 쉼표를 검사했다.
- Intro→Verse A×2→Pre→Chorus×2→Interlude→Verse B→Pre 2→Final→Outro의 56 visit에서 진행바 위치와 모든 음의 타이밍을 비교했다.
- 편집 문서 JSON 왕복과 보관함 저장/재로딩에서 반복기호·화음·TAB이 유지된다.
- 390px와 1440px 브라우저에서 악보 선택, 반복기호·구간 라벨의 SVG 내부 경계, 리듬 beam·쉼표, 진행바, Verse 끝→반복 시작 이동, Outro 탐색을 확인했다. 모바일 한 줄 1마디와 4마디 설정을 검사했다. 4마디 모드는 기존 UI처럼 악보 내부 가로 스크롤을 사용한다.
- 앱 기타 출력 엔진으로 **691개 음을 모두 스케줄링**, 56개 재생 마디의 비무음 출력과 유한 샘플 값을 확인했다. WAV 피크는 약 0.202로 클리핑이 없었다. 92 BPM의 전체 미리듣기 WAV를 함께 생성했다.
- 실제 기타 실연과 사람의 청감 평가는 수행하지 않았다. 운지 검사는 프렛 범위·현 조합·통상적인 바레 형태를 기준으로 한다.
