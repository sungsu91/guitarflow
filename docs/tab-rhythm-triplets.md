# TAB 리듬과 셋잇단음표

## 구현

- `viewSettings.tabRhythm`을 악보 문서에 저장한다. 새 악보와 설정이 없던 기존 악보는 기본 켬이다. 보기 메뉴에서 변경하며 오선보만 보기에서는 비활성화한다. PDF 인식·원본에는 영향을 주지 않는다.
- TAB 리듬은 기존 이벤트를 그대로 사용한다. 동시음 9/7도 기둥 하나다. 빔 기준선은 6번줄 아래 `2 × 줄 간격 + 10 SVG 단위`에 둔다. 온음표는 속이 빈 기호, 2분음표는 빈 기호와 기둥, 4분음표는 기둥, 8분/16분음표는 1/2단 빔이다. 명시적 쉼표만 표준 쉼표 글리프로 표시한다.
- 자동 2+2+2+2와 이전 음 연결/끊기 설정을 유지한다. 사용자 지정 4+4도 오선보와 TAB에 함께 적용된다. 빔 수정은 음 길이와 재생 데이터를 바꾸지 않는다.
- `tuplet: {actualNotes: 3, normalNotes: 2, groupId}`를 이벤트에 저장한다. PPQ 480에서 8분 3연음은 160틱, 16분 3연음은 80틱이다. 그룹 ID는 마디 복제 시 새 ID에 맞춰 복제된다.
- VexFlow Tuplet로 오선보와 TAB의 시간 배율을 적용하고, TAB 바깥의 별도 괄호와 숫자 3을 그린다. 오선보와 TAB에 별도 음악 데이터를 만들지 않는다.
- 재생 음 길이와 빔 연속성 검사도 동일한 `ticksOf`를 사용한다. 편집 화면과 연습 화면에서 같은 이벤트의 진행 표시를 사용한다. 표시 업데이트를 위해 악보 전체를 다시 그리지 않는다.

## 입력

1. 8분 또는 16분음표를 선택한다.
2. 음 길이 옆 `3연음`을 켠다.
3. 숫자는 현재 위치에 입력한다. `1 → 2`는 시간 제한 없이 12프렛이 된다. 다음 연음 위치는 `→`로 이동한다.
4. 다시 누르면 일반 입력으로 돌아간다. 일반 프렛 입력은 자동 이동하지 않는다.

기존 3연음에 화음을 추가하려면 해당 위치와 줄을 선택해 프렛을 추가한다. 기존 동시음 추가 기능도 사용할 수 있다.

선택 음 속성의 `묶음 해제`는 세 음을 일반 음표로 바꾼다. 늘어난 길이를 수용할 빈 시간이 뒤에 있어야 한다. 없으면 변경을 막고 안내한다. `묶음 삭제`는 그 시간만 빈 자리로 바꾸며 뒤쪽 음을 당기지 않는다. 일부 음만 삭제하면 160/80틱 자리와 그룹을 보존한다. Undo/Redo를 지원한다.

현재 연음 입력은 동일 길이의 8분/16분 3:2를 지원한다. 다른 비율, 중첩 연음은 지원하지 않는다.

## 검증

- 관련 단위·회귀 테스트 39개 통과: 저장, 빈 슬롯, 기존 편집, 주법 재생, 빔 연결, 모바일 입력, 3연음.
- 60/80/137/240 BPM에서 8분 3연음 3개 = 정확히 480틱, 12개 = 1920틱. 동시음 12쌍의 시작과 길이 검증.
- 브라우저 직접 검증: 360×800, 375×812, 390×844, 393×852, 430×932, 데스크톱 1440×1000.
- 일반 2+2+2+2, 사용자 4+4, 3연음의 실제 SVG 묶음 검사. 동시음당 기둥 1개, 바깥 리듬 간격, 온음표/2분음표/쉼표/16분 2단 빔 검사.
- 실제 저장 → 새로고침 → 보관함에서 열기, TAB 리듬 끔의 보존, 3연음 입력과 Undo/Redo, Web Audio 재생 중 진행 강조 확인. 브라우저 pageerror 없음.
- 프로덕션 빌드 통과. 기존 대형 청크 경고는 남아 있다.
- 휴대폰 크기로 실행한 Chrome 검증이며 실제 iPhone 기기의 오디오 지연·터치는 별도 확인이 필요하다. 사람의 청음 비교 결과로 보고한 것은 아니다.
