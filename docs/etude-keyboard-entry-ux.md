# 악보 키보드 입력 UX — 2026-09-14 병합본

## 현재 입력 방식

- 기본은 **한 자리 연속**이다. TAB 위치를 클릭하고 숫자를 누르면 즉시 해당 프렛을 입력하며, 자동 이동이 켜져 있으면 다음 입력 위치로 이동한다. 빠른 `2323`은 네 음 `2, 3, 2, 3`이다.
- **F2** 또는 툴바의 **한 자리 연속 / 두 자리 · 420ms** 버튼으로 프렛 입력 모드를 전환한다. 팝업은 열지 않는다.
- 두 자리 모드에서 `10`, `12`, `15`, `23`, `24`를 420ms 안에 입력하면 하나의 프렛이 된다. 첫 숫자도 즉시 표시하고 완성된 두 자리 입력은 한 번의 Undo로 되돌린다. 1/2로 시작하지 않는 값은 추가 숫자를 기다릴 필요 없이 확정한다.
- 두 자리 모드에서 조합할 수 없는 다음 숫자가 들어오면 앞 숫자를 확정하고 다음 위치에 입력한다. 방향키나 선택 변경으로도 입력을 명확히 구분할 수 있다.
- 자동 이동은 데스크톱 **더보기**, 모바일 **입력 설정**에서 켜고 끈다. 끄면 현재 위치에서 수정한다. 입력 모드와 자동 이동은 각각 독립 설정이다.
- ↑↓ 줄 이동, ←→ 이전/다음 위치, R 쉼표, Delete/Backspace 현재 줄 음 삭제, Tab 오선/TAB 전환, +/- 음 길이, Ctrl/Cmd+Z Undo, Ctrl/Cmd+Shift+Z 또는 Ctrl/Cmd+Y Redo.
- 악보 끝에서는 마지막 위치를 유지하며 새 마디 추가 안내를 표시한다. 최대 64마디이며 자동으로 새 악보를 생성하지 않는다.

시간 간격만으로 `2, 3`과 `23`이라는 서로 다른 의도를 구분할 수 없다. 위의 명시적 모드와 F2는 **FRETIVA LAB에서 이번 병합 시 판단한 동작**이다. Guitar Pro의 확인된 단축키나 내부 입력 알고리즘이라고 주장하지 않는다. 커서와 숫자 중심의 기존 입력 흐름은 유지한다.

## 화면과 데이터

데스크톱: 왼쪽 문맥형 속성 / 오른쪽 악보의 두 열. 상단 중복 입력·주법·마디 탭 제거. 길이 변경은 상단에서, 속성 패널에서는 현재 길이를 확인한다. 음표 선택은 음표 속성, 마디 여백은 마디 속성, 제목 영역은 곡 정보를 연다. 마디 속성에서 위치 선택도 가능하다.

모바일은 기존 악보 입력/속성 탭과 숫자 키패드를 사용한다. 키패드가 악보 클릭 영역을 덮지 않게 일반 흐름에 배치하고 긴 툴바는 가로 스크롤을 사용한다.

짧은 길이는 선택 이벤트를 나누고 뒤에 쉼표를 만든다. 길게 바꿀 때는 연속된 일반 쉼표만 사용하고 실제 음·주법·연결 정보가 있는 이웃 이벤트는 보존한다. 맞지 않는 박자는 기존 검증 결과로 표시한다. 다른 마디의 음악 데이터/ID/수동 운지는 변경하지 않는다.

기존 구조화 데이터, VexFlow SVG, 마디별 컴파일 캐시, memoized Measure, 저장소와 마이그레이션, 원본 복원, Undo/Redo, TAB↔오선보↔재생 데이터 연결을 재사용한다. 덧줄은 기존 소유 음표의 event/string/MIDI 선택 영역을 그대로 쓴다.

## 첨부본과의 차이

첨부 문서와 코드의 원래 구현은 모든 숫자에서 420ms를 기다려 자동 이동했다. Chrome에서 `2323`(80ms 간격)이 `[23, 23, 쉼표, 쉼표]`로 입력되는 것을 재현했다. 현재 병합본은 위의 명시적 두 모드로 이를 보완한다.
