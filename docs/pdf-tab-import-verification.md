# 데스크톱 PDF TAB 전체 페이지 검증

검증일: 2026-09-30. 사용자가 지정한 `Desktop/sheet music`의 PDF 10개, 28페이지 전체를 실제 Chrome의 로컬 PDF.js/OCR importer에 넣었다. 특정 곡의 정답은 생산 코드에 넣지 않았다. 감지된 603마디가 10개 문서에 들어갔다. PDF 한 개는 문서 한 개이며 64마디 이후도 같은 악보에 남는다.

## 실제 파일 결과

입력 프렛은 각 현의 자동 입력 개수이며 정답률이 아니다. 반복 프렛은 TAB 안의 명확한 슬래시 위치에 직전 운지를 적용한 부분으로, 입력 프렛에 포함된다. 검토 마디는 숫자 또는 리듬이 미확정인 마디다. 4/4 음가 합계 통과가 전체 원본과의 정답 일치를 보장하지는 않는다.

| --- | ---: | ---: | ---: | ---: | ---: |

모든 파일에서 인식 결과의 확정 프렛 개수와 실제 문서의 음 개수가 같다. 64마디를 넘는 4개 파일도 나누지 않는다. 여러 기타 파트가 있는 파일의 마디 수는 감지한 모든 TAB 영역의 합계이며 단일 파트 곡 길이는 아니다.

## 페이지별 원본 대조

**모든 날 모든 순간**은 1페이지 20마디, 2페이지 24마디, 3페이지 13마디로 이어진다. 원본에서 직접 전사한 1·2·3·4·37·45·46·49·57마디의 207개 프렛/현 위치와 76개 이벤트의 음가·쉼표를 제작실 저장 데이터와 비교했다. 앞의 4마디만 검증하지 않고 후반 코드 변경, 반복 슬래시, 온쉼표, 마지막 점음표까지 포함한다.

수기 정답은 `scripts/verify-pdf-tab-folder-ui.mjs`에만 있으며 importer와 분리되어 있다. 전체 57마디의 자동 검토 상태는 미확정 0이고 제작실 compile issues도 0이다. 이는 57마디 모든 음의 수기 정답률 100%를 뜻하지 않는다.

이전 숫자 인식 개선에서는 A Little Further·Flower Dance·인사의 후보 240개를 확대 대조했고, 쉼표가 7로 읽히는 오류를 발견했다. 잘림 전 숫자의 윗부분도 검사한 뒤 별도 표본에서 쉼표 4개 제외·실제 7프렛 16개 유지를 확인했다. 표본 밖의 이미지 인식에는 여전히 한계가 있다.

## 수정한 원인

- 64마디로 자르던 adapter와 편집 제한: PDF 문서는 최대 512마디까지 전체 페이지를 한 문서로 연결한다. 일반 악보의 64마디 한도는 유지한다.
- 숫자가 적은 스트로크 마디: 숫자와 일치하지 않는 stem에 감점을 주면서 정상적인 아래쪽 빔 대신 빈 위쪽 결과를 선택했다. 이 선택 오류를 수정하고 TAB 내부 슬래시 형태를 검증한다.
- 짧은 16분 빔·점·쉼표: 연결된 짧은 두 번째 빔과 명확한 형태를 별도로 읽는다. 앞의 4마디를 복제하지 않고 각 원본 마디를 분석한다.
- 코드표·제목·QR 등: 실제 6줄 TAB과 정렬된 숫자만 입력하고, 코드표에서 운지를 가져오지 않는다.
- 숫자와 리듬 판단: 리듬이 불명확하더라도 검증된 프렛은 보존한다. 미확정은 검토 대상으로 남긴다.
- 개발용 체크·하단 안내·범위 선택: 가져오기 UI에서 제거했다. 파일 선택만으로 모든 페이지를 처리하고 페이지별 마디 수를 표시한다.

## 제작실·회귀 검증

10개 PDF를 각각 하나의 악보로 만들고 제작실에서 저장→닫기→재열기→재저장을 검증했다. 마디·음표·원본 좌표·검토 메타데이터가 그대로 유지됐다. 모든 페이지 이동과 마지막 마디 렌더링도 확인했다. A Little Further·모든 날 모든 순간·소나기·여수밤바다는 실제 분석 모달의 파일 선택부터 실행했고, 나머지는 동일 importer가 만든 문서를 라이브러리에 넣어 제작실에서 검증했다. 테스트는 사용자 저장소와 분리된 브라우저 컨텍스트에서 실행했다.

- PDF 인식/전체 페이지 회귀 테스트 28개 통과.
- 전체 테스트 1,520개 모두 통과. 기존 CSS 검사 2개는 실제 분리된 데스크톱 스타일 파일과 현재 음계 화면 구조를 검사하도록 갱신했다.
- 390×844 모바일에는 PDF 가져오기 UI가 렌더링되지 않는다. 데스크톱 진입·취소 및 양쪽 페이지 오류 검사 통과.
- production 빌드와 개인 미디어 배포 제외 검사 통과. 빌드 결과를 5175 포트에서 직접 실행해 모든 날 모든 순간(텍스트 PDF)과 A Little Further(이미지 OCR PDF)의 파일 선택→전체 페이지 입력→저장→재열기도 통과했다.

## 남은 한계

- 이미지 PDF의 흐린 숫자, 줄기·워터마크와 겹친 숫자는 누락될 수 있다. 이미지 PDF의 반복 슬래시·쉼표 인식도 제한적이다.
- 여수밤바다는 원본이 12/8이다. 모든 페이지와 운지는 들어오지만 현재 기본 4/4 초안에서 리듬을 정확히 재현하지 못한다. 해당 파일의 자동 통과 마디도 원본 박자가 검증됐다는 뜻은 아니다.
- 바람이 불어오는곳은 리듬이 위 오선보에만 있어 TAB 전용 인식에서 리듬을 읽지 않는다.
- 너에게난처럼 여러 기타 파트가 있는 PDF는 파트별 분리 없이 TAB 영역 순서대로 이어진다.
- 조표·템포·튜닝·카포·주법·박자 변경은 사용자 확인 대상이다. 40MB/20페이지/512마디를 초과하면 오류를 표시하고 부분 문서를 자동 생성하지 않는다.
