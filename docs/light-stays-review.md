# 빛이 머무는 자리 — 제작 및 검토 기록

기존 「달빛의 편지」, 「아직 전하지 못한 말」, 「창문을 열면」은 유지하고 네 번째 독립 악보로 추가했다. 악보연습실의 연습 유형 선택창에서 **빛이 머무는 자리**를 검색한다. E단조, 4/4, BPM 72, 표준 튜닝, 카포 없음, 중급(3.5)이다.

## 기보와 실제 연주

- 실제 줄·프렛 음표를 가진 32마디다. 손가락 번호와 자동 스트럼은 사용하지 않는다.
- 5–12마디, 13–20마디에 각각 시작·끝 도돌이를 기보한다.
- 실제 순서: `1–4 → 5–12 → 5–12 → 13–20 → 13–20 → 21–28 → 29–32`.
- 48마디 × 4박 × 60/72 = **160초**. 기본 반복은 곡 전체 한 번이다. 끝난 뒤 다시 처음으로 돌아가지 않는다.
- 1번 줄 멜로디와 반주를 독립된 두 성부로 저장·기보한다. TAB 위쪽 리듬은 멜로디, 아래쪽은 반주다. 각 성부는 마디마다 정확히 4박이고, 두 성부의 길이를 합산하지 않는다.
- 멜로디와 베이스는 매 2박 구간 시작에 같은 시점, 같은 세로 위치에서 발음한다. H의 3·2번 줄도 동시에 울린다.

## 초안에서 조정한 부분

음높이, 코드 진행, T/H의 기본 공격 시점은 유지했다. 아래 이동 구간에서만 마지막 16분음표 길이만큼 소리를 비운다. BPM 72에서 약 208ms의 이동 시간이다.

| 마디·구간 | 다음 운지 | 조정과 이유 |
| --- | --- | --- |
| 13마디 1–2박 | Em(개방) → D(5프렛) | 개방 포지션에서 하이코드로 올라갈 시간 확보 |
| 13마디 3–4박 | D(5프렛) → Em(7프렛) | 바레 포지션 이동 전 해제 |
| 15마디 1–2박 | Em(7프렛) → D(5프렛) | 높은 선율을 유지하다가 이동 직전에 해제 |
| 15마디 3–4박 | D(5프렛) → C(3프렛) | 하행 이동 전 해제 |
| 16마디 1–2박 | C(3프렛) → Bm7(2프렛) | 운지 형태 교체 및 C–B 잔음 충돌 방지 |
| 16마디 3–4박 | Bm7(2프렛) → Am(5프렛) | 포지션 상승과 바레 형태 교체 시간 확보 |
| 17마디 1–2박 | Am(5프렛) → G(개방) | 개방 포지션으로 돌아갈 시간 확보 |

위 7곳의 멜로디는 **4분음표 + 붙임줄로 연결한 점8분음표 + 16분쉼표**다. 같은 프렛이 붙임줄로 다시 표시돼도 재발음하지 않는다. 마지막 H 화음은 8분음표에서 **16분음표 + 16분쉼표**로 줄인다. 두 성부가 동시에 이동할 시간을 갖는다. 나머지 2박 멜로디는 2분음표를 유지한다.

모든 비종지 음은 같은 줄 재발음 또는 현재 운지 해제 시점까지만 울린다. 반주의 8분음표는 다른 줄의 다음 음 때문에 일괄적으로 끊지 않고, 개별 줄의 재발음 또는 해당 2박 구간 끝까지 자연스럽게 이어진다. 따라서 반주 전체에 긴 잔향을 일괄 적용한 상태가 아니다. 큰 이동 구간에서는 개방현도 함께 정리해 다음 코드에 남기지 않는다.

32마디는 요청한 6·3·2·1번 줄 개방현을 동시에 온음표로 기보한다. 마지막 화음에만 1.6초의 자연 감쇠 구간을 더 확보하며, 160초에 진행 표시가 끝나도 음원을 즉시 정지시키지 않는다. 연주 템포는 끝까지 72다.

## 실제 발음 기준 검토

- B7sus4: B–E–A–B–F♯, B7: B–D♯–A–B–F♯. **4번 줄 2→1프렛(E3→D♯3)**이 실제 반주에 들어 있다. T에서는 구간 마지막 앤, H에서는 구간 둘째 박에 그 음을 연주한다.
- Dsus4→D: 1번 줄 **3→2프렛(G4→F♯4)**이 마디의 3박에서 바뀐다.
- A파트 주제는 G4→F♯4→E4, 후렴 13–16마디는 G4–A4–B4–B4–B4–A4–G4–F♯4다.
- 12→5, 12→13, 20→13, 20→21, 27→28, 31→32의 B7→Em 연결에서 D♯의 잔음을 다음 Em까지 유지하지 않는다. 불필요한 D♯–E 충돌을 피하면서 다음 마디 첫 박은 지연하지 않는다.
- Em(add9)의 F♯는 의도한 색채음이다. B7sus4의 E, Dsus4의 G는 의도한 서스펜션이며 각각 해결한다.
- 실제 발음하는 프렛은 0–9 범위다. 하이코드는 3–5, 5–7, 7–9프렛 등 좁은 범위의 바레 운지로 검토했다. **이것은 데이터·악보상 운지 검토이며 실제 기타 실연 검증이 아니다.**

## 음량 설계

멜로디 > 베이스 > 가운데 반주 순서로 개별 성부 강약을 기록했다. T의 가운데 반주는 멜로디 강도의 49%, H는 58%, 베이스는 72%로 설정했다. 실제 출력에는 동시음 수에 따른 공통 정규화도 적용된다. A파트 두 번째 방문에서 멜로디 강도만 0.065 더한다. 14–15마디에서 고조되고 21–24마디는 0.84→0.82→0.80→0.78로 단계적으로 진정시킨다.

합성 오디오 신호의 구간 RMS는 도입 0.0101, 첫 A 0.0109, 두 번째 A 0.0111, 후렴 약 0.0122, 복귀 A 0.0108, 엔딩 0.0084였다. 최고 절댓값은 약 0.115이고 클리핑은 없었다. 160초 이후에도 잔향 신호가 있고 이후 0으로 감쇠한다. **수치 검사는 음색과 선율 균형에 대한 청음 판단을 대신하지 않는다.**
