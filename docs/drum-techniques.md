# 드럼 개별 타격 주법 구현 및 검증

## 입력·표시

- 기본 드럼 이미지를 유지하며 추가 악기 버튼을 이미지 아래에 펼친다. 사이드 스틱(37), 일렉트릭 스네어(40), 페달 하이햇(44), 라이드 벨(53)을 유지한다.
- 림샷은 스네어 MIDI 38의 `drumArticulation: "rimshot"`으로 저장한다. 사이드 스틱 37과 별개다. 같은 위치의 기본 스네어 버튼은 일반 스네어로 돌리고, 림샷 버튼은 해당 스네어를 림샷으로 바꾼다. 일괄 모드에서는 기존 일괄 입력 범위를 따른다.
- 하이햇 설정 줄에서 소리 버튼 바로 앞에 주법 메뉴를 배치한다. 부족한 너비에서는 줄바꿈하며 버튼 높이는 40px 이상이다. 기존 선택 메뉴를 재사용해 두 열, 화면 경계 제한, 자동 위/아래 열기 및 롤 하위 메뉴를 제공한다.
- 악보에서 선택한 `noteId` 하나에만 적용한다. 선택이 없으면 비활성화한다. 킥 성부의 넓은 클릭 영역이 스네어/하이햇 선택을 가리지 않도록 개별 타격 선택 영역을 마지막에 배치한다. 단일 드럼 음도 원래 타격 ID를 유지한다.
- `drumTechnique.dynamic`: accent 또는 ghost. `drumTechnique.ornament`: flam, drag, roll-1/2/3 또는 buzz. 각 그룹은 배타적이며 두 그룹은 조합 가능하다. 지우기는 이 필드만 제거한다.
- 악센트는 >, 고스트는 음표 머리 양옆 괄호, 플램/드래그는 작은 꾸밈음 1/2개다. 롤은 선택한 음 옆의 짧은 보조 기둥에 빗금을 그려 공유 기둥의 다른 동시음에 적용된 것으로 보이지 않게 한다. 버즈는 3개 빗금과 z를 함께 표시한다. 림샷은 R로 구분한다.
- × 머리는 드럼 종류의 표기이며 고스트의 강약과 무관하다. 모든 표시는 편집/열람/인쇄의 공통 SVG 경로를 사용한다.

## 재생 방식과 음원 제한

- 악센트는 기본 타격 gain의 1.4배, 고스트는 0.35배다. 전체 음량 버스와 분리된다. 샘플 자체의 다른 강도 녹음으로 교체하는 방식은 아니다.
- 플램은 본음 28ms 전 1타, 드래그는 46/23ms 전 2타를 낮은 gain으로 예약한다. 재생 시작이나 탐색 직후 미리 예약할 시간이 부족하면 꾸밈음 간격을 줄이며 본음 시점은 늦추지 않는다.
- 정량 롤: 4분음표 기준 빗금 1/2/3개는 각각 8/16/32분 간격으로 반복한다. 원래 짧은 음가에는 빗금 수만큼 추가 분할하며 점음표와 셋잇단음표의 길이/비율도 반영한다.
- 버즈 롤: 18ms 간격으로 강약을 변화시켜 샘플을 반복하는 근사 재생이다. 실제 스틱 반발이나 전용 버즈 녹음을 재현한 음원은 아니다.
- 악보의 onset, 기본 duration, 마디 길이는 바꾸지 않는다. 정지·다음 타격의 소리 해제는 예약된 꾸밈음/롤 소스 전체에 적용된다.
- `public/sounds` 및 기존 매핑을 확인했다. `rim.wav`는 현재 사이드 스틱에 연결되어 있고 실제 림샷 녹음임을 증명하는 자료가 확인되지 않는다. 따라서 **검증된 전용 림샷 음원은 없음으로 취급**한다. 현재 `림샷 (합성)`은 snare.wav와 rim.wav를 각각 0.75/0.65 gain으로 겹친 근사음이다. 일반 스네어 볼륨 증가를 진짜 림샷으로 표시하지 않는다.
- 추가 필요: 출처/사용권과 타격 종류가 확인된 실제 스네어 림샷 음원. 자연스러운 버즈가 필요하면 전용 버즈 롤 음원 또는 여러 반발/강도 샘플이 필요하다. 실제 스피커/헤드폰 청취 및 물리 모바일 장치의 터치 검증은 남아 있다.

## 검증

- `tests/drum-techniques.test.mjs`: 선택 없이 적용 금지, 동시음 격리, 배타성/조합/지우기, 추가 타격 입력 시 메타데이터 보존, 저장소 왕복, 단일 타격 ID, 타임라인 길이, 반복 횟수와 강약.
- 관련 드럼/피아노/MIDI/기타 재생 테스트 52개 통과.
- `scripts/verify-drum-techniques.mjs`: Chrome 390×844, 360×800, 1440×900에서 실제 클릭으로 적용/해제, 롤 하위 선택, 실행 취소/다시 실행, 저장/재열기, A4 인쇄 미리보기, 킥+스네어+하이햇 중 스네어만 적용, 림샷 전환 및 재생/정지 검증.
- OfflineAudioContext와 실제 배포 샘플로 악센트/고스트 에너지 차이, 플램 2타/드래그 3타, 정량 롤 간격, 버즈 반복, 림샷 2개 샘플 사용, 시작 전 정지 시 잔여 예약 소리 0 확인. 실제 음색의 자연스러움을 청취로 판정한 것은 아니다.
- 기존 조성/카포/음색 선택 메뉴 브라우저 회귀 검사도 4개 화면 크기에서 통과.
- 전체 테스트 1,218개 중 1,217개 통과. `tests/omr-adapter.test.mjs`의 슬러 없는 슬라이드 테스트 1개는 기존 재생 변경과 기대값이 불일치한다. 이번 드럼 타임라인 추가를 메모리에서 제거해 비교해도 H=3, S=4로 동일하게 재현됐다. 관련 없는 기존 변경은 수정하지 않았다.
- 배포 빌드 및 허용 미디어 검사 통과. 기존 번들 크기 경고는 유지된다.
