# 배포 전 테스트 실패 19개 조사 및 수정

| 실패 항목 | 확인한 원인과 조치 |
| --- | --- |
| 앱 시작·슈팅 기본값 | 맵 이미지를 먼저 준비하는 비동기 선택 경로와 `sourceMode` 진입 판정으로 변경됨. 고정 선택과 랜덤 선호값을 각각 보존하는 경로를 검사하도록 갱신. |
| 슈팅 스킨 탭 | 펫 탭 추가 및 순서·라벨 변경을 반영. 엠블럼 제거 검사는 유지. |
| 시계탑 렌더 순서 | 세로 고정 모드 판정 함수를 사용하도록 바뀜. 기존 레이어 순서 검사는 유지. |
| 데스크톱 보조 패널 | 스크롤바 여백을 특정 지판 화면이 아닌 데스크톱 전체에서 확보하도록 변경됨. |
| 공통 슈팅 HUD | 몬스터별 표시 문자열 `monsterPitchLabel`을 사용하도록 변경됨. |
| 데스크톱 맵 스튜디오 | 가로 렌더링 판정이 모바일 가로 모드도 포함하는 `horizontalShooterActive`로 변경됨. |
| 데스크톱 메뉴 | 초기화가 반주뿐 아니라 메트로놈 볼륨까지 포함하는 `resetSoundSettings`로 변경됨. |
| 첫 에튀드 | 기본 곡 고정 초기화 대신 전달된 `initialId`와 저장된 BPM을 사용함. 곡 선택 시 BPM 복원 검사로 갱신. |
| 용암 맵·편집 레지스트리 | 실제 결함: 배치 카탈로그가 없는 특수 맵 3개도 편집 가능으로 분류됨. `isEditableShooterMap`에서 배치 데이터 지원 여부를 검사하고 편집기 맵 선택 목록도 같은 조건으로 제한. 서버 저장 레지스트리와 편집 가능 맵 목록 일치 검사는 유지. |
| 타이머 휠 | 휠 CSS부터 파일 끝까지 검사해 뒤에 추가된 다른 화면의 scroll-snap에 오탐. 휠 CSS 구간으로 범위를 제한. |
| 리듬 가로 화면 | 반주 전체 ON/OFF 버튼·잠금 안내가 추가된 마크업을 반영. |
| 화면 회전 | 수동 새로고침 버튼까지 금지하던 전역 검사. 명시적인 클릭 핸들러 1개만 허용하고 그 외 reload 호출 금지는 유지. |
| 리듬 메트로놈 설정 | 현재 사운드 기본값은 true. 런타임 ref 연결과 저장값을 임의로 복구하지 않는 검사는 유지. |
| 데스크톱 리듬 컨트롤 | Windows CRLF와 LF 문자열 경계 비교 문제. 읽은 테스트 소스의 줄바꿈을 정규화. |
| 복합박자 | 옵션 정의가 `src/metronome/options.js`로 이동됨. 파일 문자열 대신 실제 export 데이터로 박자 수와 분모를 검사. |
| 스케일 반주 UI | CSS 주석이 여러 줄로 바뀌어 구간 검색이 실패함. 올바른 구간을 찾아 기존 크기·배치 검사를 유지. |
| 이펙트 보정 | 기존 커밋 `c51fe7b`에서 moonlight-floor Y를 22에서 18로 조정함. 배포 보정값 검사를 갱신. 로컬 override 병합 검사는 유지. |

| 몬스터 보정 | elemental C의 현재 labelOffsetX는 4. 저장된 보정값을 되돌리지 않고 테스트를 갱신. |
