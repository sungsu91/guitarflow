# 모바일 악보 보관함 메인 정리 (2026-09-15)

## 정보 구조

기존 브랜드 이미지(`/assets/branding/fretiva-lab-app-icon-master.png`) + FRETIVA LAB / 전체 메뉴 → 내 악보·에튀드 탭 → PDF 불러오기·간단 악보 만들기 → 검색·정렬 → 전체·최근 연습·즐겨찾기 → 폴더 → 악보 → 기기 저장·백업.

- 모바일 홈 버튼과 메인 안내 문구 제거. 에튀드에서는 추가 버튼을 렌더링하지 않고 기존 유형 드롭다운/쪽넘김을 유지한다.
- 모바일 정렬은 작은 메뉴로 변경. 검색, 정렬 값과 실제 필터/정렬 로직은 기존 PdfStudio 것을 그대로 사용한다.
- 루트 경로 UI 제거. 폴더 안에서만 작은 ‘‹ 내 악보 / 폴더명’ 경로가 나온다.
- 폴더/악보는 각각 한 목록 안의 행으로 표시. 배경은 통일하고 제목과 보조 정보만 표시한다. 폴더가 없는 경우 작은 빈 상태와 새 폴더 버튼을 제공한다.
- 일반 상태에는 행 관리 메뉴가 없고, 편집 상태에서 선택·폴더 이동·이름 변경·즐겨찾기·삭제·새 폴더를 제공한다.
- 기기 저장·백업은 한 줄 진입 버튼에서 모달로 연다. 기존 용량 정보/저장소 유지 요청/PDF 백업/복원 처리를 재사용하고, 목록 높이를 늘리지 않는다.
- 데스크톱은 기존 헤더, 파일 표, 검색과 native select, 백업 details를 유지한다.

## 데이터 호환

PDF IndexedDB, 편집 악보 localStorage, `fretiva.score.folders.v1`을 재사용한다. 마이그레이션이나 데이터 재생성 없이 UI만 분리했다. 화면 예시 제목/폴더는 앱 코드에 넣지 않았다. 검증용 데이터는 독립 브라우저 컨텍스트에만 저장했다.
원본 PDF 해시와 편집 악보 저장 JSON이 폴더 이동으로 바뀌지 않는 것을 확인했다. 기존 백업 범위도 유지한다(PDF 백업은 PDF 문서 대상, 직접 만든 악보는 편집기 JSON 내보내기).
