# PDF 연습 파일 이동

데스크톱 사이드바의 로고 아래에서 한국어 / English를 바로 선택할 수 있다. 기존 앱 공통 언어 상태와 저장 방식을 사용한다.

## 사용 순서

1. 내 악보에서 PDF를 불러오고 저장한다.
2. PDF를 열어 간단 편집 → 마디 설정에서 영역의 두 모서리를 지정한다. 한 구간을 1~4마디로 나눌 수 있다. 지정 후 구간을 선택하면 양끝 손잡이로 전체 폭을, 내부 경계선으로 각 마디 폭을 조절할 수 있다.
3. BPM, 박자, 필요한 마디별 박수와 반복 순서를 설정한다.
4. 악보 제목 옆의 **연습 파일 저장**으로 `.fretiva-pdf` 파일을 받는다. 모바일은 문서 메뉴에서도 저장할 수 있다.
5. 파일을 휴대폰으로 옮긴 다음 내 악보 → **연습 파일 불러오기**로 연다.

파일은 원본 PDF 바이트와 마디 위치, BPM, 박자, 반복 순서, 주석, 여백 설정 등을 함께 담는다. 기존 PDF 백업 형식과 호환되며 보관함 전체 백업도 유지한다. 같은 PDF를 연습 파일로 다시 불러오면 업데이트 확인을 표시한다. 취소하면 기존 설정을 유지하고, 확인하면 해당 악보의 연습 정보를 교체한다. 기존 전체 보관함 백업 복원은 같은 PDF를 건너뛰는 동작을 유지한다.

작성 중인 마디 영역·메모·여백 편집 또는 아직 적용하지 않은 연습 순서가 있으면 먼저 적용/취소하도록 안내한다. 브라우저 저장이 실패해도 화면에 남은 최신 설정을 파일로 내보낼 수 있다.

## 원본 및 표시 품질

- PDF를 이미지로 변환해 저장하거나 원본에 주석을 합성하지 않는다. 원본 PDF 내보내기도 그대로 유지한다.
- 데스크톱은 원본에서 최대 2배 밀도로 렌더링해 일반 모니터의 가는 선 표현을 개선한다. 기존 600만 픽셀·최대 4096px·캐시 메모리 제한은 유지한다. 모바일 렌더링 예산은 변경하지 않는다.
- 확대는 기존 25~250%, 폭 맞춤, 페이지 맞춤을 사용한다. 원본 자체가 저해상도 스캔이면 추가 세부 사항을 복원하지 않는다.
- 자동 로그인 동기화, 음표 인식, PDF 음표의 자동 음원 재생을 추가한 것은 아니다. 기존 마디 진행 표시와 메트로놈 연습을 파일로 이동하는 기능이다.

## 검증

- 자동 테스트 1,313개 통과, 프로덕션 빌드 통과. 기존 큰 번들 경고 유지.
- ko/en 각 5,121키 일치, 참조 누락 없음. 남은 한글 82건은 기존 승인 예외.
- 데스크톱 1440×1000: 언어 양방향 전환 및 새로고침 유지, 원본 PDF 가져오기, 4마디 직접 지정, BPM 변경, 작성 중 영역 내보내기 방지, 파일 다운로드 확인.
- 모바일 360×800, 375×812, 390×844, 393×852, 430×932: 파일 불러오기, 마디·BPM·메모·반복 정보 보존, 진행 표시 재생, 재내보내기, 중복 업데이트 취소/확인 검증. 브라우저 오류 없음.
- 파일 왕복 시 원본 PDF SHA-256 동일. 기존 IndexedDB 구조와 localStorage 데이터 변경 없음.
- 새 언어 선택과 파일 버튼의 잘림 없음. 기존 모바일 재생바의 긴 Previous 표시는 좁은 폭에서 잘림이 남아 있으며 이번 변경으로 생긴 문제는 아니다.
- 결과: `artifacts/pdf-transfer/results.json`, `authoring.json`, 화면 이미지. 재현 스크립트: `work/verify-pdf-transfer.mjs`, `work/verify-pdf-authoring.mjs`.
- 이번 변경은 언어 컨트롤 노출, PDF 파일 이동 UI/처리, 데스크톱 렌더링 밀도와 관련 스타일에 한정한다. 게임·튜너·오디오 판정 로직은 수정하지 않았다. 로컬 적용 상태이며 메인 배포는 진행하지 않았다.

## 마디 폭 조절 및 페이지 맞춤 후속 수정

- 편집 → 구간 선택 → 양끝 손잡이 드래그로 전체 가로 길이를 변경한다. 내부 경계선은 인접 마디 사이에서 이동하며 순서가 뒤집히지 않는다. 내부 경계는 키보드 좌우 방향키도 지원한다.
- 선택 도구와 마디 도구 모두에서 조절할 수 있다. BPM과 마디별 박수는 변경하지 않는다. 되돌리기, 다시 실행, 연습 파일 저장/불러오기를 지원한다.
- 기존 마디 데이터는 유지하고 폭 비율이 변경된 줄에만 선택적 `barEdges` 필드를 추가한다. 필드가 없는 기존 줄은 이전처럼 균등 분할한다. 잘못된 경계값을 가져오면 균등 분할로 복구한다.
- 페이지 맞춤에서는 미리보기도 표시 영역 높이에 맞추고, 스크롤바 출현 여부가 영역 크기를 바꿔 재계산을 반복하지 않도록 해당 보기만 overflow를 고정했다. 폭 맞춤과 일반 확대의 스크롤은 유지한다.
- 테스트 1,315개와 빌드 통과. ko/en 5,123키 일치. 데스크톱 1440×1000, 1280×800, 1920×1080, 1100×760에서 150% → 페이지 맞춤과 창 크기 변경 후 크기·렌더 횟수 안정, 페이지 잘림 없음 확인. 모바일 360/390/430px에서 실제 터치 이벤트로 경계·전체 폭 조절, 되돌리기, 파일 저장을 확인했다.
- 재현 스크립트: `work/verify-pdf-width.mjs`, `work/verify-pdf-width-mobile.mjs`. 로컬 반영, 미배포.

## 연속 보기·편집 후 재생·보관함 연결 후속 수정

- 연속 보기에서 이미 준비된 이웃 페이지가 현재 페이지가 되면 다음 이웃 준비 상태가 갱신되지 않던 경로를 제거했다. 화면 안과 주변 페이지를 IntersectionObserver로 렌더링하고, 각 페이지 원본 크기를 읽어 자리 높이를 유지한다. 전체 페이지를 비트맵으로 미리 생성하지 않으며 기존 캐시 제한을 유지한다.
- 자동 따라가기는 현재 줄이 표시 영역 아래 35%에 들어오면 위쪽 25%로 올린다. 문서 내부만 스크롤하며 다음 줄을 읽을 여유를 둔다. 재생 중 수동 스크롤 위치가 재생 페이지를 덮어쓰지 않도록 했다.
- 편집 후 재생은 멈췄던 박 중간이 아니라 해당 마디 시작에서 재개한다. 일반 일시정지/재개는 기존 위치를 유지한다. 공통 오디오 엔진은 변경하지 않았다.
- 연습 파일 다운로드 이름은 `원본제목 (Practice 날짜-시각).fretiva-pdf`이다. 밀리초까지 포함하며 문서 제목과 PDF 원본은 변경하지 않는다.
- 에튀드 화면의 저장 악보 선택창에 내 악보의 PDF도 포함한다. 선택하면 같은 저장 원본과 연습 설정으로 PDF 연습실을 연다. 기존 편집 가능한 악보 선택은 유지한다.
- 자동 테스트 1,317개 통과, 빌드 통과, i18n 누락 없음. 브라우저 검증은 `work/verify-pdf-followup.mjs`, 결과는 `artifacts/pdf-followup/results.json`이다. 페이지 2↔3 경계, 다음 줄 여유, 편집 후 첫 강박의 즉시 예약(1200Hz), 파일 이름, 저장 PDF 선택을 검증했다. 스피커의 실제 출력은 장치에서 별도 확인이 필요하다.
- 로컬 적용이며 미배포.

## 모바일 가로 따라가기와 연속 진행선

- 따라가기 범위를 PDF 스크롤 요소, 악보 표시 영역, 화면, 하단 재생바의 교집합으로 계산한다. 마디 영역 아래에 빔을 위한 추가 여유를 두고, 마지막 줄도 위로 올릴 수 있도록 모바일 문서 끝의 스크롤 여유를 확보했다. 표시 영역 크기가 바뀌면 현재 줄의 위치를 재검사한다.
- 모바일 상단과 데스크톱 제목 옆에 현재 위치로 이동 버튼을 추가했다. 재생 시간이나 템포를 바꾸지 않고 현재 마디가 있는 페이지와 위치로 돌아간다. 편집 중에는 비활성화한다.
- 페이지별 진행선 DOM을 유지하고 매 프레임 오디오 시계가 가리키는 실제 마디 좌표를 계산한다. React의 activeBar 갱신을 기다리며 이전 진행선을 숨기던 마디 경계의 빈 프레임을 제거했다.
- 390×844 → 844×390 회전, 800×360, 932×430, 다시 세로 전환을 단일 보기와 연속 보기에서 검증했다. 각 보기에서 549프레임·15개 마디 경계를 관측했고 숨겨진 진행선 프레임은 0개였다. 터치 화면에서 수동 스크롤 후 현재 위치 복귀, 하단 재생바와 현재 줄의 간격도 확인했다.
- 결과: `artifacts/pdf-landscape-follow/results.json`, 재현: `work/verify-pdf-landscape-follow.mjs`. 테스트 1,317개 및 빌드 통과, ko/en 5,124키 일치. 로컬 적용, 미배포.
- 기능명은 ‘PDF 연습 편집실 / PDF Practice Editor’를 제안했으며 앱 이름 자체를 변경하지는 않았다.

## 중간 간격 잘라내기

- 편집 도구에 가위(중간 간격 잘라내기)를 추가했다. 페이지 중간의 없앨 간격 위에서 아래까지 드래그하고 놓으면 페이지 폭 전체의 가로 띠를 제거하고 아래 내용을 바로 위로 연결한다. 여러 간격을 연속해서 지정할 수 있다.
- 잘라낸 정보는 `pageEdits[page].cuts`에 원본 PDF의 0~1 좌표로 저장한다. 원본 바이트와 기존 마디·메모·펜 좌표는 유지한다. 표시와 포인터 입력에 정방향/역방향 좌표 변환을 적용한다.
- 바깥 여백 자르기와 함께 사용할 수 있다. 페이지 맞춤, 연속 보기 높이, 렌더 캐시, 진행선에 잘라낸 높이를 반영한다. 렌더링은 기존 제한 내의 임시 원본 캔버스에서 남은 띠를 새 캔버스로 이어 붙인다.
- 마디 지정 영역과 겹치는 잘라내기는 거부하고 먼저 영역을 조절하도록 안내한다. 인쇄된 음표를 자동 판별하는 기능은 아니므로 간격을 직접 선택한다.
- 되돌리기/다시 실행, 해당 페이지의 잘라낸 간격 전체 복원, 원본 보기, 연습 파일 저장/불러오기 지원. 원본 PDF 내보내기는 계속 원본을 반환한다.
- 테스트 1,320개와 빌드 통과. 데스크톱 1440px, 모바일 세로 390px·가로 844px에서 두 번 잘라내기, 높이 감소, 마디·메모 정렬, 원본 바이트 보존, 되돌리기/다시 실행/복원, 마디 영역 보호, 파일 재불러오기 확인. 모바일은 터치 이벤트로 검증했다. 데스크톱 연속 보기의 줄어든 페이지 자리 높이도 확인했다.
- 결과: `artifacts/pdf-gap-cuts/results.json`, 재현: `work/verify-pdf-gap-cuts.mjs`. ko/en 키와 참조 누락 검사 통과. 로컬 반영, 미배포.
