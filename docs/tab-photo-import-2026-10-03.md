# JPG·PNG 악보 사진 → TAB 초안

후속 변경: [오선보 → 6현 TAB 및 여러 사진 가져오기](staff-to-tab-batch-2026-10-03.md). 아래는 사진 한 장의 TAB 인식만 지원하던 초기 구현 기록이다.

2026-10-03. 기존 6현 기타 TAB 인식에 JPG·JPEG·PNG 사진 입력을 추가했다. 일반 오선보 사진을 TAB으로 바꾸거나 4·5현 베이스를 인식하는 기능은 이번 변경에 포함되지 않는다.

## 사용 방법

- 모바일: **PDF ▾ → 불러오기(전환) → PDF·사진 선택** 또는 **악보 사진 촬영**.
- 데스크톱: **PDF·사진 → TAB → PDF·사진 선택**.
- 사진 한 장을 선택하고 미리보기에서 글자 방향을 확인한다. 필요하면 **90° 회전** 후 **사진 분석 → 제작실에서 열기**를 누른다.
- PDF는 기존처럼 선택 즉시 전체 페이지를 분석한다. 사진은 한 번에 한 장이다.

모바일 촬영 입력에 후면 카메라 선택 힌트인 `capture="environment"`를 지정했다. 실제 카메라·사진 선택 화면은 기기와 브라우저가 제공한다. HEIC는 지원하지 않으며 JPG 또는 PNG로 저장해야 한다.

## 구현

PDF 렌더링 결과와 사진 픽셀을 공통 `createTabPageAnalyzer`에 전달한다. TAB 줄·마디 탐지, 후보 숫자 OCR, 리듬 분석, 확대 재확인, 검토·초안 저장 로직을 공유한다. 모바일·데스크톱 UI는 기존 분리를 유지하며 촬영 입력은 모바일에만 렌더링한다.

카메라 JPEG의 방향 메타데이터는 브라우저 이미지 디코더가 적용한다. EXIF 방향 6 표본을 Chrome에서 검증했다. 미리보기에서 사용자가 방향을 다시 확인하며, 사진의 90도 회전은 실제 분석 픽셀에도 적용한다. 투명 PNG는 흰 배경에 합성한다. 사진 파일명과 입력 유형, 추가 회전 각도는 초안 메타데이터에 저장한다.

파일당 40MB, 이미지 헤더 기준 5천만 화소·한 변 20,000px까지 허용한다. 실제 분석 캔버스는 1,200만 화소·한 변 8,192px 이내다. 원본 디코딩은 분석 캔버스보다 더 많은 메모리를 쓸 수 있다. 파일 형식·크기는 픽셀 디코딩 전에 검사한다. 취소·읽기 오류·30초 디코딩 시간 초과 시 이미지 로딩과 객체 URL을 정리하고, 파일 교체 및 창을 닫을 때도 미리보기 자원을 해제한다. 서버로 사진을 업로드하지 않는다.

## 실제 검사 결과

자체 제작 TAB 정답 자료에서 사진을 만들어 실제 브라우저 OCR을 실행했다. 정답은 인식기에 전달하지 않고 결과와 별도로 비교했다. 각 정상 표본의 정답은 39개 음/뮤트, 4마디다.

| 입력 | 정확한 숫자·뮤트 | 잘못 확정된 숫자·현 | 누락 | 정확한 리듬 |
|---|---:|---:|---:|---:|
| PNG | 39 | 0 | 0 | 4/4마디 |
| JPG | 39 | 0 | 0 | 4/4마디 |
| JPEG 강한 압축 | 38 | 0 | 1 | 4/4마디 |
| 카메라 EXIF 방향 JPG | 39 | 0 | 0 | 4/4마디 |
| 옆으로 누운 PNG를 수동 회전 | 39 | 0 | 0 | 4/4마디 |
| 투명 PNG | 39 | 0 | 0 | 4/4마디 |
| 흐림·압축 JPG | 34 | 0 | 5 | 4/4마디 |

- 3도 기울인 사진, 빈 사진, 손상 사진은 안내와 함께 실패했다. 이 표본을 성공적으로 인식했다고 집계하지 않았다.
- 모든 사진 분석 종료 후 남은 Worker는 0개였다.
- 모바일 320·390·440px와 데스크톱 1440px에서 사진 선택·회전·분석·편집기 열기·초안 저장을 통과했다. 모바일↔데스크톱 전환 중 미리보기와 회전 상태도 보존됐다. 320px 미리보기 화면을 시각적으로 확인했다.
- 배포용 빌드의 390px 화면에서 사진 분석·저장까지 통과했다.
- 기존 PDF 정상/이미지 입력·구조 분석 취소·OCR 초기화 취소·구조/OCR 작업자 오류 주입 6개를 재검사해 통과했다. 모바일 PDF 미저장 편집 취소·재열기와 데스크톱 경로도 통과했다.
- 전체 자동 테스트 **1,731개 통과**, 빌드 및 배포 자산 검사 통과. 기존 큰 번들 경고는 남아 있다.

## 제한과 재현

기울기·원근·접힌 종이·그림자를 자동으로 보정하지 않는다. 악보가 화면을 채우도록 정면에서 촬영해야 한다. 흐림과 압축은 여전히 인식 누락을 일으킨다. 일반 사진 전체에 위 표의 정확도를 적용할 수 없다. 실제 iPhone/Android 카메라, Safari 파일 선택·EXIF 처리 및 기기 메모리는 이번 검사에 포함하지 않았다.
