# 리듬 트레이너 구현 및 검증

진입: 모바일 메뉴 / 데스크톱 사이드바의 리듬 트레이너, `#rhythm-trainer`.

- 첨부 design-preview.html의 세 화면을 브라우저에서 확인하고 보관함 → 설정 → 재생 흐름 구현.
- MobileLayout / DesktopLayout 분리. 패턴 모델, 저장, 편집 및 오디오 상태는 공유.
- 설정/재생 모두 흰 악보 위에 5마디 표시. 추가 마디는 내부 세로 스크롤.
- 4분/8분/16분 음표와 같은 길이 쉼표, 8분 셋잇단음표, 빔 및 셋잇단음표 괄호 표시.
- 박 선택 후 빠른 프리셋 또는 혼합 음가 입력. 입력 기호를 눌러 음표/쉼표 전환. 마디 추가·삭제.
- 2/4, 3/4, 4/4와 세 난이도 지원. 선택한 마디 구간만 랜덤 생성. 각 박은 정수 12틱으로 검증.
- BPM/음색/기준 클릭/1마디 카운트인 설정은 중앙 모달. 편집 및 스크롤 DOM 유지.
- 30–240 BPM, 우드블록/림샷/클랩, 독립 클릭, 반복, 일시정지·재개·다음 마디 지원.
- 공유 AudioContext 및 SFX 버스를 사용. 기존 메뉴 진입의 stopBackingScheduler/IDLE 처리에 연결. 이탈 시 트레이너 예약 소스만 정리.
- Web Audio 시간에 예약한 음표 onset과 동일한 시간축에서 현재 음표/쉼표 자체 색상 강조 및 얇은 세로선 계산. 별도 진행 바/CSS 재생 애니메이션 없음.
- `rifflab-rhythm-trainer-v1` 로컬 저장: 저장한 패턴 + 작성 중 초안. 비정상 저장 데이터 제외 및 저장 실패 안내.
- 한국어/영어, White/Gold Dark 연동. 악보 종이는 흰색 유지.

## 완료한 검증

- 브라우저에서 360×800, 375×812, 390×844, 393×852, 430×932 각각 설정/재생 5마디의 실제 bounding rect가 스크롤 영역 안에 있음을 확인. 가로 잘림 없음. 재생 하단 컨트롤도 viewport 내부.

- 브라우저에서 혼합 8분+16분+16분 입력, 저장 후 새로고침한 보관함, 구간 랜덤 생성, 마디 추가/삭제 확인.
- 재생 시 음표 및 쉼표 강조, 이동하는 세로선, BPM 빠른 변경, 재생 중 중앙 설정창, 일시정지 확인.
- 한국어/영어 전환, White/Gold Dark 및 다크 모달 입력 대비 확인.

- `npm run build`: 성공. 기존 큰 청크 경고 있음.
- `npm test`: 실행 시점 1,333건 중 1,326 통과, 7 실패(이후 전용 count-in 테스트 1건 추가). 전체 로그: work/rhythm-trainer-full-tests.log.

## 프리셋 및 난이도 확장

- 기존 7개 포함 한 박 프리셋 27개. 기본 / 16분 조합 / 쉼표 / 점음표 / 셋잇단음표로 분류.
- 점8분(9틱)과 점8분쉼표, 쉼표 포함 셋잇단음표 지원. 직접 입력에도 점8분 추가.
- 한 박은 항상 12틱. 셋잇단과 일반 분할의 잘못된 혼합, 마디 길이 초과, 쉼표로 연결된 이음줄 검증.
- 박의 마지막 음에서 다음 박 첫 음으로 이음줄 입력 가능. 마디 경계에서는 악보 줄 끝과 다음 줄 시작에 나눠 표시. 쉼표로 대상이 바뀌면 이음줄 정리.
- 타악기 음색은 이음줄 첫 음만 타격하고 연결 음은 재타격하지 않음. 기준 박 클릭은 독립적이며 계속 동작. 음표 강조와 커서는 연결 음 구간도 진행.
- 추천 패턴에 초급/중급/고급 각각 한 마디와 여러 마디, 총 6개 추가. 기존 5마디 예시 유지.
- 초급 랜덤은 한 마디 내 반복, 중급은 중복을 줄인 다양한 한 박 재료, 고급은 엇박의 박 넘김 이음줄 포함. 재료를 섞어 소진한 뒤 다시 채워 특정 재료의 과도한 반복 완화.
- 선택 구간 랜덤 생성은 2/4, 3/4, 4/4 및 마디 개수를 유지. 같은 결과의 연속 재생성을 회피.
- 전용 자동 테스트 14건 통과: 27개 프리셋 음가 합계, 6개 연습 패턴, 난이도/박자표별 반복 생성, 구간 보존, 이음줄 편집 복구, 점음표/이음줄 스케줄과 반복 재생 검증 포함.


## 악보 방향·카운트인·하단 편집창 (2026-09-25)

- 전역 악보 표시 설정: 자동 / 위 / 아래. 리듬 전용 단선 악보의 자동은 위 방향이다. 아래 방향은 음표 왼쪽 기둥, 아래 빔·연음 괄호, 위 이음줄로 표시하며 쉼표와 숫자는 뒤집지 않는다. 모든 미리보기·연습·편집 악보에 적용한다. 리듬 데이터와 타임라인은 변경하지 않으며 방향만 적용할 때 재생을 재설정하지 않는다.
- 박자 소리는 앱 설정을 따르거나 트레이너에서 음성·스네어 등으로 지정한다. 숫자 음성은 사전 디코딩한 one/two/three/four WAV를 Web Audio 시계에 예약한다. 브라우저 speechSynthesis의 실행 지연을 카운트인에 사용하지 않는다.
- 재생 직후 BPM 기준 한 박 동안 무음 ‘준비’를 표시하고, 숫자와 소리를 함께 1부터 진행한다. 4/4는 1→2→3→4, 2/4·3/4는 각각 2·3까지 센다. 마지막 숫자의 한 박이 모두 끝나면 첫 악보 음이 시작한다. 기준 클릭이 꺼져 있어도 카운트인은 선택한 소리로 재생한다.
- 음표/쉼표 편집만 하단 시트, BPM·음색·방향 설정은 중앙 모달이다. 390×844에서 시트 위 두 마디 표시를 확인했다. 내부 항목만 스크롤하며, 선택 박을 강조하고 가려진 선택 마디만 부드럽게 올린다. 마지막 마디 편집 후 창을 닫아도 scrollTop 506을 유지함을 확인했다.
- 전용 자동 검사 24개: 준비 한 박 무음, 2/3/4박 카운트 숫자, 음성/스네어 예약, 마지막 카운트와 첫 악보 시각 포함. 실제 브라우저의 음성 샘플 로딩, 중앙 준비·숫자 표시, 카운트 중 악보 진행선 없음, 아래 방향 및 보관함 미리보기 적용 확인.


마디별 도돌이: 패턴 편집 화면과 박 편집창의 ‘한 번 더 반복’을 켜면 해당 마디 양쪽에 도돌이표를 표시하고 두 번 연주한다. `measureRepeats` boolean 배열로 저장하며 마디 추가·삭제 시 함께 갱신한다. 전체 루프와는 별도이다. 재생 순서에서 같은 마디를 두 번 참조하므로 저장 악보를 복사하지 않는다. 강조·진행선은 두 번째 재생에서도 원래 마디 좌표를 사용한다. 도돌이 점프에서는 다음 마디로 향한 이음줄을 이어 치지 않고, 두 번째 연주 후 다음 마디로 넘어갈 때 이음줄을 적용한다. 반복/저장/소리/진행선 회귀 검증을 포함해 32개 테스트 통과.
