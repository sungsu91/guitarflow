# 표시 누락 및 모바일 겹침 수정

- 튜너: 한국어가 박힌 기존 PNG는 한국어에서 유지하고, 영어에서는 번역 리소스로 만든 SVG 배지를 사용한다. 대기·정확·근접·낮음·높음·주의의 8개 상태를 지원한다. 판정과 마이크 로직은 변경하지 않았다.
- 슈팅: 쉬움/보통 랜덤의 시작 범위 안내 및 구간 전환 안내를 표시할 때 번역한다. 카운트다운 타이밍과 난이도 데이터는 유지한다.
- 그루브: 선택된 음원 이름·툴팁·미리듣기 접근성 이름을 번역한다. 저장된 음원 ID는 그대로다. 좁은 도구막대에는 Del, Med, Step을 사용한다.
- CSS 표시 문구: 반주 접기/펼치기, 코드 선택/초기화의 pseudo-element 문구를 번역된 속성·CSS 변수에서 읽도록 변경했다.
- 모바일 리듬 화면: 메트로놈 이름은 윗줄, 소리 아이콘과 ON/OFF는 아랫줄에 둔다. 펼쳐진 설정의 Collapse 버튼은 위로 옮겨 선택 버튼과 겹치지 않도록 했다. 데스크톱 위치 규칙은 변경하지 않았다.

검증: 360×800, 375×812, 390×844, 393×852, 430×932, 1440×900에서 그루브 선택 메뉴, 튜너 ko/en 왕복, 게임 시작 안내를 확인했다. 모바일 아이콘/텍스트 및 Collapse/설정 버튼의 사각형이 겹치지 않는지도 검사한다. 기록은 `artifacts/i18n/followup/results.json`과 같은 폴더의 스크린샷에 있다.

자동 테스트 1,310개 통과, production build 및 release media 검사 통과. 두 기존 소스 검사에서 summary에 번역용 속성이 추가될 수 있도록 정규식만 갱신했다. ko/en 각 5,112개 key로 일치하며 누락·보간 불일치는 없다. CSS content의 하드코딩 한글도 다시 검색했다.

이번 수정은 로컬 반영이며 별도 메인 배포는 수행하지 않았다.
