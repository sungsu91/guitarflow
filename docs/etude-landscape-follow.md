# 에튀드 가로 연습과 자동 따라가기

## 변경 영역
- `EtudeStudio`: 별도의 확대 대화상자/악보 복제를 제거하고 같은 악보 트리에서 일반/가로 집중 배치를 전환한다. 터치 기기의 실제 뷰포트 방향과 버튼 진입이 같은 레이아웃을 사용한다. 전체화면이나 화면 방향 잠금 API에 의존하지 않는다.
- `usePracticeLayout` / `practiceLayout.css`: 가용 뷰포트·안전 영역·상단 도구 모음과 내부 악보 스크롤 영역을 구분한다. 집중 화면에서는 제목을 접고 TIP을 버튼으로 제공한다. 넓은 데스크톱 창은 자동 진입하지 않는다. 가로 도구 모음 옆 공간이 충분하면 이동형 연습 위젯을 간결하게 배치한다.
- `ScorePlayback` / `PracticeFloatingTools`: 내 악보에서 쓰는 기존 practice 재생 연결과 `useEtudeMetronome`, 악보 음원 출력을 재사용한다. 에튀드의 별도 메트로놈 인스턴스를 없앴다. 연습 시작·일시정지·재개·정지가 하나의 오디오 시계로 박자 점과 진행바를 구동한다. 악보 소리는 기본 꺼짐이며 클릭 음소거와 독립적이다. 상세 설정에서 음색·세분·공용 음량을 유지한다. 연습 박자는 악보의 마디별 박자표를 따른다.
- `Score`: 컨테이너 너비/확대율에 따라 마디와 줄을 다시 배치하고 실제 SVG 좌표에 악보 단 경계를 기록한다. 오선보+TAB을 하나의 단으로 취급한다. 음표마다 악보를 다시 그리지 않고 기존 진행바만 갱신한다.
- `usePracticeFollow` / `practiceFollowGeometry`: 보기 메뉴에 한 줄씩(기본)/페이지/끔을 제공한다. 실제 악보 단 높이와 가용 영역으로 페이지 경계를 계산한다. 줄 시작에서만 이동하고 반복 복귀·페이지 전환·모션 감소 설정에서는 즉시 이동한다. 모든 줄이 이미 렌더링되어 페이지 전환 시 별도 로딩이 없다. 마지막은 실제 스크롤 한계에서 멈춘다.
- 직접 휠·터치 이동·스크롤 키 입력 시 사용자가 '현재 위치로'를 누를 때까지 따라가기를 중단한다. 일시정지 상태에서도 현재 위치로 돌아갈 수 있다. 자동 스크롤 이벤트 자체는 중단 조건이 아니다. 위젯 전용 이동 손잡이와 백킹 손잡이는 악보 스크롤 이벤트 영역 밖에 있다.

화면 회전으로 악보 데이터·음색·BPM·재생기·따라가기 설정을 새로 생성하지 않는다. 기존 백킹루프 패널과 재생 정책을 유지하며 새 BPM 동기화 기능을 추가하지 않았다. PDF/이미지에는 적용하지 않았다. 저장 데이터와 화면별 저장 범위는 변경하지 않았다.

## 검증
- 관련 단위 테스트 40개 통과: 실제 시간/변박/반복 순서, 페이지 경계, 줄 단위 이동, 끝에서의 제한, 기존 편집/반주 관련 회귀 테스트.
- `verify-etude-landscape.mjs`: Chrome 터치·모바일 에뮬레이션의 390×844 ↔ 844×390 회전과 버튼 진입, 두 테마, 재생/일시정지 위치 유지, 악보 소리 기본 꺼짐, 클릭 음소거, 악보 소리를 켠 상태의 회전, 줄/페이지/끔, 직접 스크롤과 일시정지 중 현재 위치 복귀, 보기/125% 확대, 두 손잡이 드래그, 백킹 패널 열기/닫기 통과. 각 테스트 세션의 AudioContext는 1개, 페이지 오류 없음. 1440×900 일반 데스크톱이 자동 가로 모드에 진입하지 않음을 확인.
- `verify-etude-landscape-rhythm.mjs`: 브라우저 메모리 안에서만 사용한 시험 악보로 점음표 뒤 쉼표(750 tick), 셋잇단음표(1134 tick), 4/4→3/4→6/8→4/4, 240→180 BPM, 도돌이표 복귀 시 즉시 원래 줄로 이동 확인. 재생 중 SVG 객체가 유지됨을 확인. 시험 악보를 앱 목록이나 사용자 저장소에 추가하지 않음.
- `verify-saved-practice.mjs` 및 기존 `verify-etude-playhead-rhythm.mjs`: 내 악보 무음/소리 전환/박자·반복 및 기존 악보 재생 회귀 검증 통과.
- 빌드 성공. 기존 큰 번들 경고는 남아 있음.

## 확인하지 못한 환경
실제 휴대폰 회전 센서, iOS Safari, 모바일 브라우저 주소창의 실제 접힘 동작, 블루투스 출력 지연과 실기기 청감은 검증하지 않았다. 방향 변경/창 크기 변경은 Chrome 에뮬레이션으로 확인했으며, 음원 동기화는 브라우저 오디오 시계와 재생 상태 기준으로 검증했다.

결과: `artifacts/etude-landscape/`의 JSON·로그·테마별 캡처.

## 후속 도구 배치 수정
- 보기 트리거는 현재 표시 방식(오선보 + TAB / 오선보만 / TAB만)과 변경 화살표를 표시한다.
- 에튀드의 세로/가로 툴바에 메트로놈·백킹루프 버튼을 나란히 배치했다. 우측 가장자리 백킹 손잡이는 에튀드에서 제거했다. 내 악보 화면의 기존 손잡이는 유지한다.
- 메트로놈은 기본 접힘이며, TIP·메트로놈·백킹 패널을 바꾸어 열 때 다른 패널만 접는다. 연습/백킹 재생은 중단하지 않는다.
- TIP은 상단 왼쪽 아래에서 열고, 테마 표면과 글자 대비를 명시하여 다크 테마의 흐린 글자 문제를 수정했다.
- 기타/피아노 소리는 기본 해제된 '악보 소리 듣기 (선택)' 체크박스로 제공한다. 해제 중 음색 선택은 비활성화하며, 다른 악보를 고르면 다시 해제된다.
- `verify-practice-tools-update.mjs`: 두 테마, 세로/가로 전환, 기본 악보 음원 출력 0회, 체크 전환 중 진행 유지, 백킹 패널 접기 후 재생 표시 유지, 페이지 오류 없음 확인. 결과 캡처와 빌드 로그는 `artifacts/practice-tools-update/`.
