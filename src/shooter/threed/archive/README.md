# Archived portrait 3D prototype

`ThreeDLabPortraitRenderer.jsx` and `three-d-lab-portrait.css` preserve the
original front-facing portrait 3D experiment. They are intentionally not
imported by the production map renderer.

The active `입체 실험실` map uses `ThreeDLabHorizontalRenderer.jsx` on desktop
and on mobile landscape. Restore this archived renderer only when a separate
front-facing 3D mode is designed.
