# FRETIVA LAB 슈팅게임 펫 스프라이트 팩 v1

코드 적용용 완성 패키지입니다. 동물 10종, 각 3동작, 동작당 8프레임으로 총 240프레임입니다.

## 구성

- `pets.manifest.json`: 전체 펫·동작·행 번호·재생 속도 정보
- `pets/{petId}/atlas.png`: 2048×768 RGBA PNG 아틀라스
- `pets/{petId}/thumbnail.png`: 선택 UI용 첫 프레임
- `pets/{petId}/{action}/frame_00.png`~`frame_07.png`: 256×256 개별 프레임

각 아틀라스는 8열×3행입니다. 한 행에 한 동작이 들어가며 왼쪽에서 오른쪽으로 재생합니다.

## 바로 적용하는 방법

1. 이 팩의 `pets` 폴더를 프로젝트의 `public/assets/pets` 아래로 복사합니다.
2. `pets.manifest.json`을 함께 복사하고 이 파일을 기준으로 펫 목록과 동작을 로드합니다.
3. 기존 슈팅게임 로직은 수정하지 말고 펫 렌더러만 별도 컴포넌트로 연결합니다.
4. 선택된 펫의 아틀라스만 지연 로딩합니다. 10종 전체를 시작 시점에 한꺼번에 불러오지 않습니다.
5. 충돌 판정은 이미지 알파 영역을 사용하지 말고 현재 게임의 고정 hitbox를 유지합니다.

## Canvas 절단 규칙

```js
const CELL = 256;
const sx = frameIndex * CELL;
const sy = action.row * CELL;

ctx.drawImage(
  atlas,
  sx, sy, CELL, CELL,
  petX - 128 * scale,
  petY - 224 * scale,
  CELL * scale,
  CELL * scale
);
```

- 논리 앵커: `x=128`, `y=224`
- 좌우 이동은 프레임 이미지에 넣지 말고 게임 좌표로 처리합니다.
- 반대 방향이 필요하면 별도 이미지를 만들지 말고 렌더 단계에서 `scaleX(-1)`을 사용합니다.
- 프레임 전환 시간은 `1000 / fps`로 계산합니다.

## 적용 안전 규칙

- 기존 플레이어 기타, 음표 몹, 피격 판정, 점수, 난이도 및 오디오 엔진을 변경하지 않습니다.
- 펫은 시각적 동반자 레이어로만 추가하며 게임 판정에 참여시키지 않습니다.
- 기본 상태는 각 펫의 첫 번째 동작을 재생합니다.
- 두 번째·세 번째 동작은 점수 획득, 콤보, 피격 성공 또는 일정 시간 간격 같은 기존 이벤트를 구독해 재생하고 완료 후 기본 상태로 돌아오게 합니다.
- CSS 확대보다 Canvas 또는 이미지 렌더러의 정수 배율/좌표 스냅을 우선해 잔떨림을 방지합니다.
- 360×800, 375×812, 390×844, 393×852, 430×932에서 펫이 하단 UI나 기타 플레이어를 가리지 않는지 확인합니다.

## 검증 완료 항목

- 모든 아틀라스 2048×768
- 모든 개별 프레임 256×256
- 동물 10종 × 3동작 × 8프레임 = 240프레임
- RGBA PNG 및 투명 배경
- 프레임 번호·격자선·워터마크 없음
- 햄스터 동작에 생성됐던 불필요한 반응 기호 제거

이미지는 생성 후 알파 번짐을 정리한 적용용 파일이며, 원본 생성 이미지 대신 이 폴더 안의 파일만 사용합니다.
