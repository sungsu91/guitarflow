# Codex 전달문

첨부한 `fretiva_pet_sprite_pack_v1.zip`을 사용해 FRETIVA LAB 슈팅게임에 펫 애니메이션 10종을 적용해주세요.

이 파일은 최종 적용용 에셋 팩입니다. 이미지는 다시 생성하거나 재편집하지 말고, 압축 안의 `pets.manifest.json`과 `README_KO.md`를 기준으로 구현해주세요.

## 작업 범위

- 펫 10종과 각 펫의 3개 시그니처 동작을 추가합니다.
- 각 동작은 8프레임이며 아틀라스는 2048×768, 셀은 256×256, 배열은 8열×3행입니다.
- 아틀라스 방식과 개별 프레임 방식이 모두 들어 있으므로 현재 슈팅게임 렌더링 구조에 더 안전한 방식을 선택해주세요.
- 선택된 펫만 지연 로딩하고, 기본 동작은 매니페스트에 등록된 첫 번째 동작으로 설정해주세요.
- 두 번째·세 번째 동작은 기존 점수·콤보·명중 이벤트를 구독해 자연스럽게 재생한 뒤 기본 동작으로 복귀하게 해주세요.

## 변경 금지

- 기존 기타 플레이어 위치와 조작
- 음표 몹 생성 및 피격 판정
- 발사체, 점수, 콤보, 난이도, 오디오 및 튜너 관련 로직
- 현재 정상 작동 중인 슈팅게임의 게임 루프

펫은 별도의 시각 레이어와 독립 컴포넌트로 추가하고 게임 판정에는 포함하지 마세요. 기존 파일을 광범위하게 리팩터링하지 말고 최소 변경으로 연결해주세요.

## 완료 검증

- 투명 배경에 사각형 잔상이나 색 번짐이 없는지 확인
- 프레임 전환 시 캐릭터 중심이 불필요하게 좌우로 떨리지 않는지 확인
- 동작 시작과 종료가 갑자기 끊기지 않는지 확인
- 360×800, 375×812, 390×844, 393×852, 430×932에서 기타 플레이어와 하단 UI를 가리지 않는지 확인
- iPhone Safari 및 홈 화면 추가 PWA에서 로딩·재생이 정상인지 확인
- 에셋 경로 404, 콘솔 오류, 기존 기능 회귀가 없는지 확인

작업 완료 후 변경 파일 목록, 적용한 렌더링 방식, 펫별 이벤트 연결표, 기기별 검증 결과를 보고해주세요.
