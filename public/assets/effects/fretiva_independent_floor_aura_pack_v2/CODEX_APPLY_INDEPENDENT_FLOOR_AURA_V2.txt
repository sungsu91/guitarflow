FRETIVA LAB - INDEPENDENT FLOOR & AURA PACK V2
================================================

이 파일이 최종 적용 명세입니다.

0. 적용 기준
-----------
- 이 ZIP만 신규 10종 적용 기준으로 사용합니다.
- 이전 `fretiva_floor_aura_pair_pack_v1.zip`과 결합형 SET 에셋은 사용하지 않습니다.
- 본 V2의 플로어와 아우라는 결합 이미지를 잘라 만든 것이 아니라 각각 독립 생성된 원본입니다.
- 현재 적용된 불꽃/용암, 달빛, 은하 오비탈, 숲 넝쿨 에셋은 그대로 유지하고 덮어쓰거나 중복 등록하지 않습니다.

1. 반드시 독립 선택
------------------
- `floor`와 `aura`는 서로 다른 카테고리, ID, 선택 상태, 저장 키를 사용합니다.
- 동일 제목과 `sort_order`는 목록에서 대응 컨셉을 찾기 쉽게 하기 위한 표시 규칙일 뿐입니다.
- 같은 이름을 선택했다고 자동으로 함께 선택하거나 SET 객체로 합치지 않습니다.
- 사용자는 어떤 플로어와 어떤 아우라도 자유롭게 섞어 사용할 수 있어야 합니다.

2. 파일과 표시 제목
-----------------
- 정확한 파일명, 화면 표시 제목, ID, 순서는 `skin_manifest.json`을 그대로 사용합니다.
- FLOOR: `floors/<TITLE>_FLOOR.png`
- AURA: `auras/sheets/<TITLE>_AURA_8F.png`
- 모든 PNG는 투명 RGBA이며 배경 영역은 alpha 0입니다.

3. 플로어 렌더링
---------------
- 플로어는 1536x1024 단일 고정 PNG입니다.
- 플로어에는 프레임 애니메이션, 흔들림, 확대/축소 펄스, 회전, opacity 반복을 적용하지 않습니다.
- 플로어를 아우라 타이머나 아우라 transform wrapper 안에 넣지 않습니다.
- `bottom_center` 기준으로 기타 발밑에 고정합니다.

4. 아우라 렌더링
---------------
- 각 아우라 시트는 1536x1024, 4열 x 2행, 총 8프레임입니다.
- 프레임 크기는 384x512입니다.
- 프레임 인덱스 계산:
  `column = frameIndex % 4`
  `row = Math.floor(frameIndex / 4)`
- Canvas 사용 시 source rect:
  `sx = column * 384`, `sy = row * 512`, `sw = 384`, `sh = 512`
- 각 항목의 `frame_duration_ms`로 0 -> 1 -> ... -> 7 -> 0 정방향 반복합니다.
- ping-pong, 시트 전체 이동, 같은 프레임의 단순 translate/rotate 복사로 대체하지 않습니다.
- `prefers-reduced-motion`에서는 0번 프레임으로 고정합니다.

5. 레이어 순서
-------------
뒤에서 앞으로 아래 순서를 고정합니다.
1) 맵
2) 선택된 아우라의 현재 프레임
3) 선택된 플로어 고정 PNG
4) 기타
5) 음표/판정/HUD

- FRONT 아우라 레이어를 만들지 않습니다.
- 같은 아우라를 기타 앞에 한 번 더 복사하지 않습니다.
- 아우라가 기타 바디 위를 이불처럼 덮으면 잘못 적용된 것입니다.
- `mix-blend-mode: screen/add`를 강제하지 말고 `normal`을 사용합니다.
- 런타임 blur, hue-rotate, drop-shadow로 색이나 크기를 과장하지 않습니다.

6. 크기와 불투명도
----------------
- 초기 크기와 불투명도는 각 항목의 `default_scale`, `default_opacity`를 사용합니다.
- PNG 자체 알파와 manifest opacity를 한 번만 적용합니다.
- 모든 아우라를 opacity 1.0으로 강제하지 않습니다.
- 플로어와 아우라의 위치/크기 조정값을 서로 공유하지 않습니다.

7. 상태와 성능
-------------
- 예시 저장 키: `selectedFloorSkinId`, `selectedAuraSkinId`처럼 독립시킵니다.
- 기존 선택값과 기존 에셋 ID를 보존합니다.
- 선택된 아우라 시트만 렌더링하고 선택 해제 시 animation loop를 정리합니다.
- `useEffect` dependency array는 렌더마다 길이가 바뀌는 조건부 배열을 사용하지 않습니다.
- `none` 상태 때문에 dependency를 spread로 추가/삭제하지 말고 항상 같은 길이와 순서를 유지합니다.

8. 완료 확인
-----------
- 기존 4개 컨셉이 유지된다.
- 신규 FLOOR 10개와 AURA 10개가 각각 추가된다.
- 두 목록의 신규 항목이 동일 제목/동일 순서로 보인다.
- 플로어만 바꾸어도 아우라 선택은 유지된다.
- 아우라만 바꾸어도 플로어 선택은 유지된다.
- 플로어는 완전히 고정되고 아우라만 8프레임으로 움직인다.
- 기타가 아우라보다 항상 앞에 보인다.
- 콘솔에 dependency array size 경고가 없다.
