FRETIVA LAB LOW PROFILE GUITAR STAND PACK V1 - PROMPT SUMMARY
============================================================

생성 방식
- 내장 이미지 생성 도구로 각 에셋을 1장씩 독립 생성했습니다.
- 여러 디자인을 한 장에 만든 뒤 잘라낸 이미지가 아닙니다.

공통 프롬프트 기준
- 최종 모바일 게임용 단독 기타 스탠드 플로어
- 1536x1024 투명 RGBA PNG, 배경 alpha 0
- 정면 3/4 원근의 넓고 낮은 받침
- 기타는 포함하지 않음
- 중앙과 상부는 기타 바디 및 좌우 약 12도 기울임을 위해 개방
- 높은 기둥, 폴, 등받이, 목 받침, 아치, 벽, 세로 장애물 금지
- 아우라, 연기, 파티클, 마법 효과 금지
- 기타 뒤에 배치되는 정적 플로어로 설계
