FRETIVA LAB - LOW PROFILE GUITAR STAND PACK V1
================================================

이 파일이 최종 적용 명세입니다.

0. 적용 범위
-----------
- ZIP의 `stands/` 폴더에 있는 투명 PNG 10개를 기존 단독 플로어(FLOOR/FLOOR 2) 선택 목록에 추가합니다.
- 파일명, 화면 표시 제목, ID, 정렬 순서는 `skin_manifest.json`을 그대로 사용합니다.
- 기존 플로어, 아우라, 기타 스킨은 유지하며 덮어쓰지 않습니다.
- 이 10종은 아우라나 SET이 아니라 정적인 장식용 기타 스탠드 플로어입니다.

1. 핵심 구현 방식
----------------
- 실제 안착 기능, 충돌 판정, 물리 연산, 별도 스탠드 상태를 만들지 않습니다.
- 현재 고정된 기타의 기준 좌표에 스탠드 PNG를 `bottom_center`로 맞춰 뒤에 겹칩니다.
- 기타의 기존 위치, 크기, 회전 중심, 주파수 입력 반응은 변경하지 않습니다.
- 스탠드는 기타 transform의 자식으로 넣지 말고 같은 플레이 영역의 독립 sibling 레이어로 둡니다.

2. 레이어 순서
-------------
뒤에서 앞으로 아래 순서를 유지합니다.
1) 맵
2) 선택된 아우라(있는 경우)
3) 선택된 스탠드 플로어 PNG
4) 기타
5) 음표, 판정, HUD

- 스탠드 이미지는 항상 기타 뒤에 렌더링합니다.
- 기타 앞에 스탠드 사본이나 FRONT 레이어를 만들지 않습니다.
- 기타가 스탠드 위에 안착한 것처럼 보이는 효과는 좌표 정렬과 원근만으로 처리합니다.

3. 좌우 흔들림 보호
------------------
- 기타는 기존처럼 좌우로 기울어도 됩니다.
- 좌우 기울임 transform은 기타에만 적용하고 스탠드는 완전히 고정합니다.
- 제작 기준상 기타 바디 주변에 좌우 각 12도 이상의 빈 공간이 확보되어 있습니다.
- 스탠드에 맞추기 위해 기타 기울임 각도나 이동 범위를 줄이지 않습니다.
- 높은 기둥, 목 받침, 등받이, 아치, 세로 장애물을 런타임에서 추가하지 않습니다.

4. 이미지 처리
-------------
- 모든 원본은 1536x1024 sRGBA PNG이며 배경 영역은 alpha 0입니다.
- PNG를 JPG/WebP로 변환하거나 불투명 배경을 합성하지 않습니다.
- 비율을 유지하고 `contain` 방식으로 사용합니다. 가로·세로를 서로 다르게 늘리지 않습니다.
- CSS 필터, 강제 그림자, 과도한 glow, hue-rotate를 추가하지 않습니다.
- 스탠드는 애니메이션, 흔들림, 회전, 펄스, opacity 반복 없이 완전히 고정합니다.

5. 선택 및 저장
-------------
- 기존 플로어 선택 상태와 저장 키를 그대로 사용합니다.
- 별도의 SET 자동 선택이나 아우라 자동 연결을 만들지 않습니다.
- 다른 아우라와 자유롭게 조합할 수 있어야 합니다.
- 동일 ID가 이미 존재하면 중복 등록하지 말고 충돌을 보고합니다.

6. 완료 확인
-----------
- 신규 스탠드 플로어 10종이 manifest 순서대로 보인다.
- 파일명과 화면 제목이 정확히 일치한다.
- 스탠드를 선택해도 기타 위치와 기울임 동작이 바뀌지 않는다.
- 기타가 좌우로 기울 때 스탠드가 같이 돌지 않는다.
- 기타 바디가 스탠드 뒤에 가려지지 않는다.
- 스탠드는 완전히 고정되어 있고 아우라만 별도 동작한다.
- 기존 플로어, 아우라 및 선택 저장값이 유지된다.
