FRETIVA LAB 인형뽑기방 맵 V2 적용 지침

이 버전은 기존 적용을 교체하는 수정본입니다. 과거의 기계 전체 스프라이트와 확대·축소 애니메이션은 제거합니다.

1. 모바일에서는 runtime/FRETIVA_GACHA_ARCADE_MAP_BASE_RUNTIME.png를 배경으로 사용합니다. 세 뽑기 기계와 별 조명의 천장 고정부는 이미 배경에 합쳐져 있습니다.
2. 움직이는 레이어는 좌측 중앙 집게, 우측 상단 집게, 우측 하단 집게, 별 조명 링 네 개뿐입니다.
3. 집게 시트는 6열×4행, 24프레임, 4fps, 총 6초 반복입니다. 프레임 순서는 좌→우, 위→아래입니다.
4. 집게 동작은 시작점 대기 → 짧은 가로 이동 → 정지 → 수직 하강 → 닫힘 → 정지 → 수직 상승 → 원위치 복귀 → 대기입니다. 이미지 전체 확대·축소와 대각선 이동을 추가하지 않습니다.
5. 각 집게 프레임 크기 자체가 유리창 마스크입니다. manifest의 placement 좌표에 그대로 배치하고 overflow:hidden 또는 Canvas clipRect를 반드시 유지합니다. 집게가 기계 장식부나 유리창 밖으로 나가면 좌표를 임의 보정하지 말고 manifest 값으로 복구합니다.
6. 좌측 기계 집게는 좌측 벽에서 시작해 오른쪽으로 조금 이동합니다. 우측 두 기계는 우측 벽에서 시작해 왼쪽으로 조금 이동합니다.
7. 별 조명은 6열×4행, 24프레임, 6fps입니다. 링과 전체 크기는 고정되고 별 조명만 시계 방향으로 순차 점등됩니다. transform:scale 애니메이션을 적용하지 않습니다.
8. 렌더 성능을 위해 프레임마다 React state를 갱신하지 않습니다. CSS steps() 배경 위치 또는 Canvas의 공용 애니메이션 타이머 하나를 사용합니다. 화면 이탈과 document.hidden 상태에서는 타이머를 정지합니다.
9. 세 집게는 0ms, 1800ms, 3600ms의 시작 지연을 적용합니다. 모든 장식 애니메이션을 동시에 같은 프레임에서 시작하지 않습니다.
10. preview/FRETIVA_GACHA_ARCADE_V2_COMPOSITE.png는 위치 확인용입니다. 실제 적용은 통합 배경과 네 애니메이션 레이어를 사용합니다.
11. 인형뽑기방 맵을 기본맵으로 설정하되 사용자가 이미 직접 선택해 저장한 맵 값은 덮어쓰지 않습니다.
12. 모바일 390×844에서 집게가 레일에 붙어 있는지, 유리창 밖으로 넘치지 않는지, 별 조명 크기가 변하지 않는지 확인한 후 배포합니다.
