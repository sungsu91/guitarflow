FRETIVA LAB PINK INSTRUMENT SKINS V1 - PROMPT SUMMARY
====================================================

생성 방식
- 내장 이미지 생성 도구로 세 악기를 각각 독립 생성했습니다.
- 한 장의 시트를 자른 이미지가 아닙니다.

디자인
- ROSE QUARTZ: 로즈쿼츠 그라데이션, 자개 꽃잎, 로즈골드 바인딩
- PINK ORBIT: 펄 핑크, 아이보리 오비탈 픽가드, 로즈골드 궤도선
- VELVET BLOOM: 더스티 로즈, 월넛 중심재, 버건디 꽃 인레이

공통 조건
- 정면 수직, 전체 악기 표시
- 어쿠스틱/일렉 6현·노브 3+3
- 베이스 4현·노브 2+2
- 투명 RGBA 배경 alpha 0
- 텍스트, 실제 브랜드, 배경, 스탠드 없음
