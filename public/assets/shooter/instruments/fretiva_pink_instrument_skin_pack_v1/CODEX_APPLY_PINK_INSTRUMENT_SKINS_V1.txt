FRETIVA LAB - PINK INSTRUMENT SKIN PACK V1
==========================================

이 파일이 최종 적용 명세입니다.

1. 적용 범위
-----------
- 기존 기타 스킨은 유지합니다.
- 신규 핑크 스킨을 각 카테고리에 1종씩 추가합니다.
- 어쿠스틱: ROSE QUARTZ
- 일렉: PINK ORBIT
- 베이스: VELVET BLOOM
- 파일명, 화면 제목, ID, 경로는 `skin_manifest.json`을 그대로 사용합니다.

2. 구조
------
- ROSE QUARTZ와 PINK ORBIT은 6현, 튜닝 노브 좌 3 + 우 3입니다.
- VELVET BLOOM은 4현, 튜닝 노브 좌 2 + 우 2입니다.
- 이미지에 현이나 노브를 코드/CSS로 추가하거나 복제하지 않습니다.
- 모든 이미지는 정면 수직이므로 별도 회전 보정을 적용하지 않습니다.

3. 이미지 처리
-------------
- 모든 이미지는 1024x1536 sRGBA PNG이며 배경은 alpha 0입니다.
- JPG 변환, 배경색 합성, 자동 배경 제거 재처리를 하지 않습니다.
- 원본 비율을 유지하고 기존 기타 렌더 박스에서 `contain`으로 표시합니다.
- 헤드와 바디 끝을 자르거나 가로·세로를 다르게 늘리지 않습니다.

4. 렌더링 및 상태
----------------
- 기존 기타와 같은 `bottom_center` 앵커를 사용합니다.
- 기존 좌우 기울임, 타격, 복귀 동작을 그대로 사용합니다.
- 플로어·아우라보다 앞에, 음표·HUD보다 뒤에 렌더링합니다.
- 기존 스킨 선택값을 유지하고 신규 스킨으로 자동 변경하지 않습니다.
- CSS hue-rotate, 강제 glow, 과도한 drop-shadow로 색상을 바꾸지 않습니다.

5. 완료 확인
-----------
- 세 이미지가 정확한 악기 카테고리에 표시된다.
- 파일명과 화면 표시 제목이 manifest와 일치한다.
- 어쿠스틱/일렉은 6현·노브 6개, 베이스는 4현·노브 4개로 보인다.
- 기타가 기울지 않은 정면 수직 상태로 로드된다.
- 검정·흰색·체크무늬 배경이 생기지 않는다.
- 기존 스킨과 선택 저장값이 유지된다.
